# 趣学伴 2.0 UI 设计系统

> 版本：2.0 设计方向稿（Professional SaaS）  
> 目标：从深色作战指挥中心切换为「专业 SaaS 风格」——干净、克制、清晰、可信赖，以蓝灰为主色，白底卡片 + 极淡阴影，宽敞透气的桌面端体验。

---

## 1. 设计目标与原则

### 1.1 核心定位
- **风格**：专业、冷静、现代 SaaS，类似 Linear / Notion / Figma 的工具感
- **终端**：桌面优先，同时保证移动端可用
- **信息密度**：中高，强调「一扫即懂」的效率
- **情绪**：让家长感到「清晰、可控、专业」

### 1.2 设计原则
1. **一致性**：所有页面共用同一套 Token 与组件，禁止各页面自行造样式
2. **可读性**：大字体、高对比、层级分明
3. **克制与留白**：用留白和间距建立层级，而不是边框和装饰
4. **去装饰化**：不用渐变、玻璃拟态、霓虹光、重阴影
5. **效率优先**：每个元素都服务于操作、状态或决策

### 2.5 阴影

## 3. 全局组件规范

### 3.1 按钮

| 类型 | 样式 | 用途 |
|------|------|------|
| Primary | `bg-primary text-white` + 8px 圆角 + 高度 36px | 主操作：新建、保存、确认 |
| Secondary | `bg-white border border-default text-primary` | 次操作：编辑、配置 |
| Ghost | `text-secondary hover:bg-subtle` | 低频操作、文字链接 |
| Danger | `text-danger hover:bg-red-50` | 删除、取消 |
| Icon Button | 32px × 32px 圆角 8px | 工具栏操作 |

- 按钮默认高度：`36px`（标准），`28px`（小）
- 图标 + 文字间距：`6px`
- Hover：背景色变深或 `bg-subtle`，**无位移、无缩放**
- Active：背景色略深
- Disabled：透明度 0.5，无 hover

### 3.2 卡片

**标准卡片**：
```
背景：bg-elevated (#ffffff)
边框：1px solid border-subtle
圆角：radius-lg (12px)
内边距：24px
阴影：shadow-card
hover：shadow-card-hover + border-default
```

**卡片结构约定**：
- 顶部：标题 + 可选操作
- 中部：内容
- 底部：可选操作栏（右对齐或两端对齐）
- 一个产品里只允许 1–2 种卡片结构

### 3.3 输入框

```
高度：36px
背景：bg-elevated
边框：1px solid border-default
圆角：radius-md (8px)
内边距：10px 12px
字号：14px
Focus：border-primary + shadow-focus
Placeholder：text-tertiary
Error：border-danger + 红色提示文字
```

### 3.4 标签 / Badge

```
默认：bg-subtle + text-secondary + border-subtle
胶囊：radius-full
分类标签：可带颜色点（颜色点直径 5px）
难度标签：保留颜色编码（简单绿 / 中等黄 / 困难红）
标签高度：20px
```

### 3.5 弹窗 / Modal

```
遮罩：rgba(15, 23, 42, 0.35)
容器：bg-elevated + radius-xl (16px) + shadow-popup
最大高度：max-h-[85vh]
宽度：sm:max-w-md / md:max-w-lg / lg:max-w-2xl
z-index：50+，必须覆盖左侧导航
内容：超出可滚动
关闭按钮：右上角 ghost icon
```

### 3.6 导航

**顶部栏**：
- 高度：`56px`
- 背景：bg-elevated
- 左侧：页面标题 + 面包屑（可选）
- 右侧：孩子切换、通知、用户头像
- 底部边框：`1px solid border-subtle`

**左侧边栏**：
- 宽度：`w-56`（224px）
- 背景：bg-elevated
- 菜单项：图标 + 文字，14px 字重 500
- Active：左侧 3px 蓝色指示条 + `text-primary` + `bg-subtle`
- Hover：`bg-subtle`
- 图标统一尺寸：18px

### 3.7 表格 / 矩阵

- 表头：`bg-subtle` + `text-secondary` + 12px 字
- 单元格：垂直居中，内边距 12px 16px
- Hover 行：`bg-subtle/50`
- 边框：仅保留横向 1px `border-subtle`
- 当前行：左侧 3px 蓝色指示条

### 3.8 进度条

```
背景：border-subtle
填充：bg-primary
高度：6px（细）/ 8px（标准）
圆角：radius-full
```

## 4. 页面布局规范

### 4.1 页面标题区（统一结构）

```jsx
<div className="flex flex-col sm:flex-row sm:items-center sm:justify-between gap-4 mb-8">
  <div className="flex items-center gap-3">
    <h1 className="text-heading-1">页面标题</h1>
  </div>
  <div className="flex items-center gap-2">
    {/* 操作按钮 */}
  </div>
</div>
```

- 入场动画：`opacity 0→1`，200ms，**无位移**

### 4.2 内容区

- 最大宽度：桌面 `1280px` 居中
- 默认内边距：`32px`
- 卡片流：
  - 单列：移动
  - 两列：平板 / 小桌面
  - 三列：大桌面

### 4.3 首屏仪表盘（建议方向）

布局从上至下：
1. 欢迎/今日概览（白色大卡片）
2. 今日任务卡片流（2 列桌面）
3. 本周进度 + 关键提醒（左右分栏）
4. 快捷入口（图标列表）

## 5. 动效规范

### 5.1 缓动曲线

- 默认：`cubic-bezier(0.4, 0, 0.2, 1)`
- 出现/消失：`cubic-bezier(0.4, 0, 0.2, 1)`

### 5.2 时长

| 类型 | 时长 |
|------|------|
| 微交互（hover、focus）| 100–150ms |
| 入场动画 | 150–200ms |
| 页面切换 | 150ms |
| 弹窗出现 | 150ms |
| 成功反馈 | 200ms |

### 5.3 常用动画

- **卡片入场**：`opacity 0→1`，stagger 30ms，**无位移**
- **按钮 hover**：背景色/边框色变化，**无位移、无缩放**
- **弹窗出现**：`opacity 0→1` + 轻微 `scale(0.98→1)`
- **加载骨架**：pulse 动画，1.5s 循环

### 5.4 减弱动画

- 尊重 `prefers-reduced-motion`
- 提供 `data-reduced-motion="true"` 全局开关

## 6. 图标与插图

### 6.1 图标

- 统一使用 `lucide-react`
- 线条风格：1.5px stroke，圆角线端
- 尺寸：16px（小）/ 18px（默认）/ 20px（大）
- 图标颜色默认 `text-tertiary`，active 用 `primary`

### 6.2 任务卡片图标

沿用已有的 6 个分类 SVG 图标，统一调整为：
- viewBox：`0 0 24 24`
- strokeWidth：`1.5`
- strokeLinecap / strokeLinejoin：`round`
- 颜色：`text-secondary` 或 `primary`

### 6.3 插图 / 空状态

- 空状态使用简洁线性插画 + 蓝色点缀
- 避免卡通、高饱和度、复杂场景

## 7. 响应式策略

### 7.1 断点

| 断点 | 宽度 | 布局 |
|------|------|------|
| `sm` | 640px | 单列，底部导航 |
| `md` | 768px | 单列/双列 |
| `lg` | 1024px | 左侧边栏展开，双列卡片 |
| `xl` | 1280px | 三列卡片 |
| `2xl` | 1536px | 最大 1280px 居中 |

### 7.2 移动端适配原则

- 左侧导航自动收起为底部导航
- 卡片单列全宽
- 弹窗改为底部 sheet 或全屏
- 按钮高度不低于 44px

   - 改造 `Button`、`Card`、`Modal`、`Input`、`Badge`
   - 改造 `Topbar`、`Sidebar`、`MobileBottomNav`
   - 建立 `PageHeader` 统一标题组件

3. **Phase 3：首屏仪表盘**
   - 新建/重写 `app/dashboard/page.tsx`

4. **Phase 4：逐页迁移**
   - 今日任务 (`today`)
   - 任务库 (`task-library`)
   - 规划工具 (`plan`、`subjects/*`、`toolbox/*`)

### 8.2 当前代码需迁移的点

- 当前 `globals.css` 为深色主题（`#050508`），需整体替换为浅色 Token
- `tailwind.config.ts` 中 `background`、`surface`、`text-*` 等颜色需重新映射
