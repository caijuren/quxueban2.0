# v2.7.0 工程化规范

> 版本：v2.7.0 Foundation  
> 目标：通过工程化手段保证 Design Token 和组件规范被持续执行。  
> 状态：规范文档（待实现）

---

## 1. 目标与范围

### 1.1 目标

1. 禁止新增硬编码颜色、间距、阴影等样式。
2. 统一 className 书写顺序，提升可读性。
3. 建立组件和样式的文件组织规范。
4. 让设计系统的维护成本降到最低。

### 1.2 范围

- Web 端代码：`app/`、`components/`、`lib/`。
- 配置文件：`.eslintrc.json`、`.prettierrc` / `prettier.config.js`、`tailwind.config.ts`。
- 不覆盖 `miniapp/`、`prisma/`、`scripts/`、`public/`。

---

## 2. 设计原则

1. **规则即文档**：能自动化检查的，不写进人工 checklists。
2. **渐进式严格**：新规则先以 warn 引入，团队适应后再提升为 error。
3. **不增加无意义负担**：规则要解决问题，不是为了规则而规则。
4. **工具优先于人**：用 Prettier、ESLint、TypeScript 守住底线。

---

## 3. Prettier 配置

### 3.1 安装依赖

```bash
pnpm add -D prettier prettier-plugin-tailwindcss
```

### 3.2 配置文件

新建 `.prettierrc`：

```json
{
  "semi": true,
  "singleQuote": true,
  "tabWidth": 2,
  "trailingComma": "es5",
  "printWidth": 100,
  "plugins": ["prettier-plugin-tailwindcss"],
  "tailwindFunctions": ["cn", "clsx"]
}
```

### 3.3 作用

- `prettier-plugin-tailwindcss` 会按官方推荐顺序自动排列 Tailwind class：
  1. Layout（`display`, `position`, `width`, `height`）
  2. Box Model（`padding`, `margin`, `border`）
  3. Typography（`font`, `text`, `color`）
  4. Visual（`bg`, `shadow`, `opacity`）
  5. Misc（`transform`, `transition`, `animate`）

### 3.4 运行方式

```bash
# 检查格式
pnpm prettier --check .

# 自动修复
pnpm prettier --write .
```

建议 CI 中加入 `prettier --check`。

## 4. ESLint 规则

### 4.1 安装依赖

当前已安装 `eslint` 和 `eslint-config-next`。v2.7.0 需要新增：

```bash
pnpm add -D eslint-plugin-tailwindcss
```

### 4.2 配置更新

更新 `.eslintrc.json`：

```json
{
  "extends": [
    "next/core-web-vitals",
    "plugin:tailwindcss/recommended"
  ],
  "plugins": ["tailwindcss"],
  "rules": {
    "tailwindcss/classnames-order": "off",
    "tailwindcss/enforces-shorthand": "warn",
    "tailwindcss/no-contradicting-classname": "error",
    "tailwindcss/no-custom-classname": "off",
    "tailwindcss/no-unnecessary-arbitrary-value": "warn",
    "no-restricted-syntax": [
      "error",
      {
        "selector": "Literal[value=/^#[0-9a-fA-F]{3,8}$/]",
        "message": "禁止硬编码颜色，请使用 Design Token。"
      }
    ]
  },
  "overrides": [
    {
      "files": ["app/globals.css", "**/*.css"],
      "rules": {
        "no-restricted-syntax": "off"
      }
    }
  ]
}
```

### 4.3 规则说明

| 规则 | 级别 | 说明 |
|---|---|---|
| `tailwindcss/classnames-order` | off | 由 Prettier 处理，避免重复报错。 |
| `tailwindcss/enforces-shorthand` | warn | 提示使用 `mx-4` 代替 `ml-4 mr-4`。 |
| `tailwindcss/no-contradicting-classname` | error | 禁止冲突 class，如 `block hidden`。 |
| `tailwindcss/no-custom-classname` | off | 允许自定义 Token class。 |
| `tailwindcss/no-unnecessary-arbitrary-value` | warn | 提示不必要的任意值，如 `w-[100px]` 可改为 `w-25`。 |
| `no-restricted-syntax`（硬编码颜色） | error | 禁止 `bg-[#FF0000]`、`#FFFFFF` 等硬编码色值。 |

### 4.4 硬编码颜色例外

以下情况允许硬编码颜色：

1. `app/globals.css` 中定义 Token 本身。
2. 复杂图表/可视化组件（需在代码注释中说明，并在 v2.7.4 归档）。
3. 营销页特殊效果（需在注释中说明 `/* marketing-only: not part of design system */`）。

例外必须加注释，否则 ESLint 报错。

## 5. className 书写规范

### 5.1 必须走 Prettier

所有 `className` 字符串必须经过 Prettier 自动排序。不允许手动维持固定顺序。

### 5.2 条件 class 使用 `cn` 工具

统一使用 `lib/utils.ts` 中的 `cn` 函数：

```tsx
import { cn } from '@/lib/utils';

<button
  className={cn(
    'inline-flex items-center justify-center rounded-lg px-4 py-2 text-sm font-medium',
    'transition-colors focus-visible:outline-none focus-visible:ring-2',
    variant === 'primary' && 'bg-primary text-text-primary hover:bg-primary/90',
    variant === 'secondary' && 'bg-surface text-text-secondary border border-border-default',
    isLoading && 'cursor-not-allowed opacity-70',
    className
  )}
>
  {children}
</button>
```

### 5.3 禁止的写法

```tsx
// ❌ 直接拼接字符串，难以维护
className={`px-4 py-2 ${isActive ? 'bg-primary' : 'bg-surface'}`}

// ❌ 使用三元表达式嵌套复杂逻辑
className={isActive ? (isDisabled ? 'a' : 'b') : 'c'}

// ❌ 硬编码任意值
className="w-[123px] h-[45px]"

// ✅ 正确写法
className={cn('px-4 py-2', isActive ? 'bg-primary' : 'bg-surface')}
```

### 5.4 样式分组

复杂组件的 className 建议按逻辑分组：

```tsx
className={cn(
  // Layout
  'flex items-center justify-between gap-4',
  // Box model
  'w-full rounded-xl border border-border-default p-4',
  // Visual
  'bg-surface shadow-sm transition-all',
  // State
  'hover:border-border-strong hover:bg-surface-hover',
  // Custom
  className
)}
```

分组注释可选，但推荐在原子组件中使用。

## 6. 文件组织规范

### 6.1 目录结构

```
components/
├── ui/                    # 原子组件 + 分子组件
│   ├── Button.tsx
│   ├── Input.tsx
│   ├── Card.tsx
│   ├── Badge.tsx
│   ├── Select.tsx
│   ├── DataTable.tsx
│   ├── FormField.tsx
│   └── ...
├── layout/                # 布局组件
│   ├── AppShell.tsx
│   ├── PageHeader.tsx
│   ├── PageContainer.tsx
│   └── ...
├── settings/              # 业务模块组件
├── dashboard/
├── console/
├── weekly/
└── providers/             # 全局 Provider
```

### 6.2 组件文件命名

- 使用 PascalCase：`Button.tsx`、`DataTable.tsx`
- 一个文件一个默认导出组件
- 组件 props 类型使用 `XxxProps`

### 6.3 样式文件

- 全局样式只放在 `app/globals.css`。
- 不允许为单个组件创建 `.module.css` 或独立 `.css` 文件（特殊情况需审批）。
- 组件样式全部用 Tailwind class 写在 TSX 中。

## 7. 组件编写规范

### 7.1 原子组件模板

```tsx
'use client';

import * as React from 'react';
import { cn } from '@/lib/utils';

export interface ButtonProps
  extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'primary' | 'secondary' | 'ghost' | 'danger';
  size?: 'xs' | 'sm' | 'md' | 'lg';
  isLoading?: boolean;
}

const Button = React.forwardRef<HTMLButtonElement, ButtonProps>(
  (
    {
      className,
      variant = 'primary',
      size = 'md',
      isLoading = false,
      children,
      disabled,
      ...props
    },
    ref
  ) => {
    return (
      <button
        className={cn(
          'inline-flex items-center justify-center gap-2 rounded-lg font-medium',
          'transition-colors focus-visible:outline-none focus-visible:ring-2',
          'focus-visible:ring-primary/50 focus-visible:ring-offset-2',
          'disabled:pointer-events-none disabled:opacity-60',
          variant === 'primary' && 'bg-primary text-text-primary hover:bg-primary/90',
          variant === 'secondary' &&
            'bg-surface text-text-secondary border border-border-default hover:bg-surface-hover',
          variant === 'ghost' &&
            'bg-transparent text-text-secondary hover:bg-surface-hover hover:text-text-primary',
          variant === 'danger' && 'bg-error/10 text-error hover:bg-error/20',
          size === 'xs' && 'h-7 px-2.5 text-xs',
          size === 'sm' && 'h-8 px-3 text-xs',
          size === 'md' && 'h-10 px-4 text-sm',
          size === 'lg' && 'h-12 px-6 text-base',
          isLoading && 'cursor-wait opacity-80',
          className
        )}
        ref={ref}
        disabled={disabled || isLoading}
        {...props}
      >
        {isLoading && <Spinner className="mr-1 h-4 w-4" />}
        {children}
      </button>
    );
  }
);
Button.displayName = 'Button';

export default Button;
```

### 7.2 组件必须满足

- [ ] 使用 TypeScript，props 有完整类型定义。
- [ ] 支持 `className` 扩展。
- [ ] 支持 ref 转发（交互组件）。
- [ ] 只使用 Design Token，不硬编码颜色。
- [ ]  disabled/loading 状态样式统一。
- [ ] 有 `displayName`（使用 forwardRef 时）。

## 8. 主题切换实现规范

### 8.1 控制方式

通过 `data-theme` 属性控制：

```ts
// lib/theme.ts
export type Theme = 'light' | 'dark' | 'system';

export function setTheme(theme: Theme) {
  const root = document.documentElement;
  if (theme === 'system') {
    const systemTheme = window.matchMedia('(prefers-color-scheme: dark)').matches
      ? 'dark'
      : 'light';
    root.setAttribute('data-theme', systemTheme);
  } else {
    root.setAttribute('data-theme', theme);
  }
  localStorage.setItem('theme', theme);
}
```

### 8.2 初始化

在 `app/layout.tsx` 或 `components/providers/SettingsApplier.tsx` 中：

```tsx
useEffect(() => {
  const saved = localStorage.getItem('theme') as Theme | null;
  const theme = saved ?? 'dark';
  setTheme(theme);
}, []);
```

### 8.3 服务端渲染注意

为避免主题闪烁，建议在 HTML 初始化时用内联脚本：

```tsx
// app/layout.tsx
<script
  dangerouslySetInnerHTML={{
    __html: `
      (function() {
        const theme = localStorage.getItem('theme') || 'dark';
        if (theme === 'system') {
          const systemTheme = window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
          document.documentElement.setAttribute('data-theme', systemTheme);
        } else {
          document.documentElement.setAttribute('data-theme', theme);
        }
      })();
    `,
  }}
/>
```

### 8.4 与现有变体兼容

保留 `lib/settings.ts` 中的 `THEME_COLORS` 和 `applySettingsToDocument`，用于品牌色变体：

- `data-theme`：控制整体明暗。
- `applySettingsToDocument`：覆盖 `--color-primary` 等品牌色。

`AppearanceSection` 后续拆分为：
- 外观主题：`light` / `dark` / `system`
- 品牌变体：`dark-tech` / `rose-pink`（仅 dark 模式）

## 9. Git 提交规范

采用 Conventional Commits：

```
<type>(<scope>): <subject>
```

v2.7.x 阶段建议使用以下 type：

| Type | 用途 |
|---|---|
| `feat(ds)` | 新增 Design System 功能或组件 |
| `fix(ds)` | 修复 Design System 问题 |
| `docs(ds)` | Design System 文档更新 |
| `refactor(ds)` | 重构样式/组件 |
| `chore(ds)` | 工程化配置更新 |

示例：

```
feat(ds): add Button and Input atom components
refactor(ds): replace hardcoded colors in admin pages with tokens
docs(ds): add v2.7.0 token specification
```
