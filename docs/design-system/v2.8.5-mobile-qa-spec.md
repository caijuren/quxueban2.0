# 趣学伴 Design System v2.8.5 — 移动端适配与 QA 发布

> 版本：v2.8.5
> 目标：确保 v2.8.x 视觉升级在移动端同样出色，完成全局回归并发布 v2.8.0。

---

## 1. 背景

v2.8.4 已完成数据可视化与状态组件升级。当前移动端仍存在以下问题：

- 部分页面信息密度过高，小屏幕拥挤
- Glass 卡片在移动端数量过多，视觉层次混乱
- 设置页左侧导航在小屏幕无法使用
- 点击区域偏小，部分按钮低于 44px
- 图表在移动端展示不完整
- 缺少系统化的视觉/功能/性能回归

v2.8.5 将进行移动端专项适配和全局 QA，最终发布 v2.8.0。

---

## 2. 设计原则

1. **移动优先检查**：每个改动都需要验证 iPhone SE / 12 / 14 Pro Max 三种尺寸。
2. **减少 Glass 密度**：移动端单屏 strong Glass 不超过 1 个，default Glass 不超过 2 个。
3. **增大触控区域**：所有可点击元素 ≥ 44px。
4. **单列优先**：复杂布局在移动端自动降级为单列。

---

## 3. 移动端适配

### 3.1 首页 `/dashboard`

- 顶部概览卡单列堆叠
- 快捷入口卡 3 张改为 1 列或 2 列（根据屏幕宽度）
- 数据摘要卡单列堆叠
- 减少 strong Glass 卡片数量
- 底部操作区增大点击区域 ≥ 44px

### 3.2 成长报告 `/dashboard/reports`

- 报告头部 Hero 区保持，但减少 padding
- 学科分析卡片单列堆叠
- 完成率圆环在移动端缩小尺寸
- 趋势图改为横向滚动或简化展示
- Heatmap 打卡热力图保持可点击格子 ≥ 44px

### 3.3 AI 模块 `/dashboard/ai`、`/dashboard/ai-assistant`

- AI 诊断卡片单列
- 对话输入框固定在底部
- 消息气泡宽度适配（最大宽度 85%）
- 推荐问题横向滑动或纵向堆叠

### 3.4 设置中心 `/dashboard/settings/*`

- 左侧导航在移动端变为顶部 Tab 或抽屉
- 表单单列布局
- Section 卡片减少 padding
- 危险操作区增加确认提示，避免误触

### 3.5 今日任务 `/dashboard/today`

- 任务卡片单列
- 打卡按钮增大点击区域
- 录音/上传图片按钮 ≥ 44px

### 3.6 周计划 `/dashboard/weekly`

- 周计划表格改为卡片列表
- 日期切换器横向滚动
- 任务项点击区域 ≥ 44px

---

## 4. 响应式断点

沿用 Tailwind 默认断点：

| 断点 | 宽度 | 说明 |
|---|---|---|
| `sm` | 640px | 小屏手机 |
| `md` | 768px | 大屏手机/平板竖屏 |
| `lg` | 1024px | 平板横屏/小桌面 |
| `xl` | 1280px | 桌面 |

移动端主要指 `sm` 及以下，重点检查 `max-w-[375px]`（iPhone SE）、`390px`（iPhone 12）、`430px`（iPhone 14 Pro Max）。

## 8. 技术实现要点

### 8.1 移动端导航

- 使用 `Sheet` 抽屉或顶部 `Tabs` 替代左侧导航
- 默认隐藏桌面侧边栏，移动端显示汉堡菜单或 Tab

### 8.2 触控区域

- 按钮最小高度 `min-h-[44px]`
- 图标按钮最小尺寸 `44px × 44px`
- 列表项最小高度 `48px`

### 8.3 Playwright 视觉回归

```ts
// 示例：首页截图对比
test('dashboard visual regression', async ({ page }) => {
  await page.goto('/dashboard');
  await page.waitForLoadState('networkidle');
  await expect(page).toHaveScreenshot('dashboard.png', {
    maxDiffPixels: 100,
  });
});
```

### 8.4 Lighthouse CI

- 在 CI 或本地运行 `lighthouse-ci`
- 阈值：Performance ≥ 85，Accessibility ≥ 90，Best Practices ≥ 90

## 10. 风险与应对

| 风险 | 影响 | 应对策略 |
|---|---|---|
| 移动端 Glass 效果过多导致拥挤 | 视觉混乱 | 减少移动端 Glass 密度，强 Glass 仅保留 Hero |
| Playwright 截图不稳定 | 误报 | 设置合理 maxDiffPixels，排除动态内容 |
| 功能回归遗漏 | 线上问题 | 按核心流程清单逐项验证 |
| 发布当天环境异常 | 服务中断 | 保留旧镜像，支持快速回滚 |
| 包体积因图表库增加 | 首屏变慢 | 按需加载，tree-shaking |
