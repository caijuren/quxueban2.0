# 趣学伴 Design System v2.8.0 — Liquid Glass Foundation

> 版本：v2.8.0
> 目标：将 Apple Liquid Glass 视觉语言纳入 Design System，提供统一的 Token、工具类与 GlassCard 组件，为后续页面改造奠定基础。

---

## 1. 背景

v2.7.x 已完成 Design Token 与组件库基础建设，并支持深色/浅色/系统主题切换。v2.8 阶段将重点提升界面质感，引入 Liquid Glass（液态玻璃）设计语言，让核心页面呈现通透、分层、有科技感的视觉效果。

v2.8.0 作为 Foundation 阶段，不直接改造大量页面，而是先建立可复用的 Glass 能力：

- 扩展 Design Token
- 提供 CSS 工具类
- 提供 `GlassCard` 组件
- 在首页做最小可用 Demo

---

## 2. 设计原则

1. **可控的通透感**：Glass 效果用于高价值区域，不滥用。
2. **主题自适应**：同一套 Token 在深色/浅色下自动呈现不同质感。
3. **可读性优先**：Glass 背景上的文字必须保证对比度。
4. **性能友好**：避免大面积 backdrop-filter，提供降级方案。

## 3. Token 扩展

在 `app/globals.css` 中新增以下 Token，放在 `:root` 和 `:root[data-theme='light']` 下。

### 3.1 Glass 背景

| Token | 深色值 | 浅色值 | 说明 |
|---|---|---|---|
| `--glass-bg-subtle` | `rgba(17, 21, 34, 0.40)` | `rgba(255, 255, 255, 0.40)` | 弱玻璃背景 |
| `--glass-bg-default` | `rgba(17, 21, 34, 0.55)` | `rgba(255, 255, 255, 0.55)` | 标准玻璃背景 |
| `--glass-bg-strong` | `rgba(17, 21, 34, 0.70)` | `rgba(255, 255, 255, 0.70)` | 强玻璃背景 |

### 3.2 Glass 边框

| Token | 深色值 | 浅色值 | 说明 |
|---|---|---|---|
| `--glass-border-subtle` | `rgba(255, 255, 255, 0.06)` | `rgba(0, 0, 0, 0.06)` | 弱边框 |
| `--glass-border-default` | `rgba(255, 255, 255, 0.10)` | `rgba(0, 0, 0, 0.10)` | 标准边框 |
| `--glass-border-strong` | `rgba(255, 255, 255, 0.14)` | `rgba(0, 0, 0, 0.14)` | 强边框 |

### 3.3 Glass 高光与阴影

| Token | 深色值 | 浅色值 | 说明 |
|---|---|---|---|
| `--glass-highlight` | `rgba(255, 255, 255, 0.08)` | `rgba(255, 255, 255, 0.45)` | 顶部高光 |
| `--glass-shadow-color` | `rgba(0, 0, 0, 0.35)` | `rgba(0, 0, 0, 0.12)` | 投影颜色 |

### 3.4 Blur 半径

| Token | 值 | 说明 |
|---|---|---|
| `--glass-blur-subtle` | `12px` | 弱模糊 |
| `--glass-blur-default` | `20px` | 标准模糊 |
| `--glass-blur-strong` | `32px` | 强模糊 |

### 3.5 Glow 光晕

沿用现有 Token，不新增：

- `--shadow-primary`: `rgba(244, 63, 122, 0.22)`
- `--shadow-secondary`: `rgba(139, 92, 246, 0.22)`

GlassCard 可通过组合生成 glow 效果。

## 4. CSS 工具类

新增以下工具类到 `app/globals.css`：

```css
.glass {
  background: var(--glass-bg-default);
  backdrop-filter: blur(var(--glass-blur-default));
  -webkit-backdrop-filter: blur(var(--glass-blur-default));
  border: 1px solid var(--glass-border-default);
  box-shadow:
    inset 0 1px 0 0 var(--glass-highlight),
    0 8px 24px -4px var(--glass-shadow-color);
}

.glass-subtle {
  background: var(--glass-bg-subtle);
  backdrop-filter: blur(var(--glass-blur-subtle));
  -webkit-backdrop-filter: blur(var(--glass-blur-subtle));
  border: 1px solid var(--glass-border-subtle);
  box-shadow:
    inset 0 1px 0 0 var(--glass-highlight),
    0 4px 12px -2px var(--glass-shadow-color);
}

.glass-strong {
  background: var(--glass-bg-strong);
  backdrop-filter: blur(var(--glass-blur-strong));
  -webkit-backdrop-filter: blur(var(--glass-blur-strong));
  border: 1px solid var(--glass-border-strong);
  box-shadow:
    inset 0 1px 0 0 var(--glass-highlight),
    0 16px 40px -8px var(--glass-shadow-color);
}

/* _hover 状态：抬升 + 阴影扩散 */
.glass-hover {
  transition: transform var(--duration-fast) var(--ease-out),
    box-shadow var(--duration-fast) var(--ease-out);
}

.glass-hover:hover {
  transform: translateY(-2px);
  box-shadow:
    inset 0 1px 0 0 var(--glass-highlight),
    0 24px 48px -8px var(--glass-shadow-color);
}
```

## 5. GlassCard 组件

### 5.1 API

```tsx
interface GlassCardProps {
  children: React.ReactNode;
  strength?: 'subtle' | 'default' | 'strong';
  hover?: boolean;
  glow?: 'none' | 'primary' | 'secondary' | 'ai';
  className?: string;
  as?: keyof JSX.IntrinsicElements;
}
```

### 5.2 变体说明

| Prop | 默认值 | 说明 |
|---|---|---|
| `strength` | `'default'` | 玻璃强度 |
| `hover` | `false` | 是否启用悬停抬升 |
| `glow` | `'none'` | 光晕颜色 |
| `as` | `'div'` | 渲染元素 |

### 5.3 Glow 实现

Glow 通过伪元素 `::before` 实现，避免影响布局：

```css
.glass-glow-primary::before {
  content: '';
  position: absolute;
  inset: -1px;
  border-radius: inherit;
  background: transparent;
  box-shadow: 0 0 40px var(--shadow-primary);
  opacity: 0.6;
  z-index: -1;
  pointer-events: none;
}
```

注意：GlassCard 需要 `position: relative` 才能承载 glow 伪元素。

### 5.4 使用示例

```tsx
import GlassCard from '@/components/ui/glass-card';

// 标准玻璃卡片
<GlassCard>内容</GlassCard>

// 强玻璃 + 悬停抬升
<GlassCard strength="strong" hover>
  核心数据
</GlassCard>

// AI 模块带紫色光晕
<GlassCard strength="strong" glow="ai" hover>
  AI 诊断结果
</GlassCard>
```

## 8. 注意事项

1. **backdrop-filter 性能**：GlassCard 内部避免嵌套多层 Glass，移动端必要时降级为实色。
2. **可读性**：Glass 上放置文字时，建议文字颜色使用 `text-primary` 或 `text-inverse`，确保对比度。
3. **z-index**：使用 glow 时，父容器需有明确的 stacking context，避免光晕被裁切。
4. **不要使用硬编码**：业务代码中禁止直接写 `backdrop-filter` 或 `rgba` 背景色，统一使用 GlassCard 或工具类。
