# v2.7.0 Design Token 规范

> 版本：v2.7.0 Foundation  
> 目标：建立完整、可切换、可扩展的 Design Token 体系，支撑深色/浅色双主题。  
> 状态：规范文档（待实现）

---

## 1. 目标与范围

### 1.1 目标

1. 让项目中所有视觉属性（颜色、间距、圆角、阴影、字体、动效）都有 Token 对应。
2. 支持深色/浅色主题切换，业务代码不感知具体色值。
3. 建立 Token 命名规范，新增 Token 时有章可循。
4. 为后续原子组件库提供唯一视觉来源。

### 1.2 范围

- 覆盖 Web 端（`app/`、`components/`）的所有样式属性。
- 不覆盖小程序端（`miniapp/`），小程序保持现有样式独立。
- 不改动 API 和数据库。

### 1.3 不在范围

- 营销页的特殊视觉效果（保留但归档）。
- 复杂数据可视化配色（单独在 v2.7.4 数据可视化 Token 中处理）。

---

## 2. 设计原则

1. **Token 即真理**：任何视觉值都必须来自 Token，不允许硬编码。
2. **语义化命名**：Token 名描述用途，不描述色值。例如 `--border-default` 而不是 `--gray-200`。
3. **分层管理**：
   - **Global Token**：最底层原始值（如 `#FFFFFF`、`12px`）。
   - **Alias Token**：语义化别名（如 `--bg-card`、`--text-primary`）。
   - **Component Token**：组件级变量（可选，复杂组件使用）。
4. **主题切换最小化**：切换主题时，只切换 Global/Alias Token，不动业务代码。
5. **向后兼容**：保留现有深色主题作为默认，新增浅色主题不破坏现有页面。

## 3. 现有 Token 审计

当前 `app/globals.css` 已定义的 Token：

| 类别 | 已有 Token | 评价 |
|---|---|---|
| 背景 | `--bg-primary`, `--bg-header`, `--bg-card`, `--bg-card-hover`, `--bg-elevated` | 完整，需扩展浅色值 |
| 品牌色 | `--color-primary`, `--color-primary-glow`, `--color-primary-dim`, `--color-secondary`, `--color-secondary-glow`, `--color-secondary-dim` | 完整，但由 JS 动态设置 |
| AI 色 | `--ai-primary`, `--ai-glow` | 可与 secondary 合并或保留 |
| 状态色 | `--success`, `--warning`, `--danger` | 缺少 info |
| 文字 | `--text-primary` ~ `--text-disabled` | 完整，需扩展浅色值 |
| 边框 | `--border-default`, `--border-primary`, `--border-ai` | 缺少 strong/subtle 分级 |
| 阴影 | `--shadow-primary`, `--shadow-secondary`, `--shadow-card` | 缺少层级 |
| 字体 | `--font-display`, `--font-body`, `--font-mono` | 完整 |

**缺失**：间距、圆角、阴影层级、字号、字重、动效、Z-index。

## 4. Token 分类规范

### 4.1 颜色 Token

颜色 Token 分三层：

#### 4.1.1 背景色（Background）

| Token | 深色值 | 浅色值 | 用途 |
|---|---|---|---|
| `--bg-primary` | `#090B12` | `#FFFFFF` | 页面主背景 |
| `--bg-secondary` | `#0D1018` | `#F8FAFC` | 次级背景、侧边栏 |
| `--bg-header` | `#0D1018` | `#FFFFFF` | 顶部 Header |
| `--bg-card` | `#111522` | `#FFFFFF` | 卡片背景 |
| `--bg-card-hover` | `#171C2B` | `#F8FAFC` | 卡片 hover |
| `--bg-elevated` | `#1C2233` | `#FFFFFF` | 浮层、下拉、弹窗 |
| `--bg-overlay` | `rgba(0,0,0,0.65)` | `rgba(0,0,0,0.35)` | 模态框遮罩 |
| `--bg-disabled` | `rgba(255,255,255,0.04)` | `rgba(0,0,0,0.04)` | 禁用背景 |

#### 4.1.2 文字色（Text）

| Token | 深色值 | 浅色值 | 用途 |
|---|---|---|---|
| `--text-primary` | `#F8FAFC` | `#111827` | 标题、重要文字 |
| `--text-secondary` | `#CBD5E1` | `#4B5563` | 正文、描述 |
| `--text-tertiary` | `#94A3B8` | `#6B7280` | 辅助说明 |
| `--text-muted` | `#64748B` | `#9CA3AF` | 占位符、时间 |
| `--text-disabled` | `#475569` | `#D1D5DB` | 禁用文字 |
| `--text-inverse` | `#111827` | `#FFFFFF` | 在彩色背景上的文字 |

#### 4.1.3 边框色（Border）

| Token | 深色值 | 浅色值 | 用途 |
|---|---|---|---|
| `--border-subtle` | `rgba(255,255,255,0.04)` | `rgba(0,0,0,0.04)` | 弱分割线 |
| `--border-default` | `rgba(255,255,255,0.08)` | `rgba(0,0,0,0.08)` | 卡片/输入框默认边框 |
| `--border-strong` | `rgba(255,255,255,0.11)` | `rgba(0,0,0,0.12)` | hover 边框、强调分割线 |
| `--border-primary` | `rgba(244,63,122,0.45)` | `rgba(244,63,122,0.50)` | 主色强调边框 |
| `--border-ai` | `rgba(139,92,246,0.45)` | `rgba(139,92,246,0.50)` | AI 模块强调边框 |

#### 4.1.4 品牌色（Brand）

品牌色保留现有变量，由 `data-theme` 和主题变体共同决定：

| Token | 默认值 | 用途 |
|---|---|---|
| `--color-primary` | `#F43F7A` | 主按钮、激活状态、重点 |
| `--color-primary-glow` | `#FB7185` | 渐变终点、发光效果 |
| `--color-primary-dim` | `rgba(244,63,122,0.12)` | 主色浅底 |
| `--color-secondary` | `#8B5CF6` | AI 模块、次强调 |
| `--color-secondary-glow` | `#6366F1` | AI 渐变终点 |
| `--color-secondary-dim` | `rgba(139,92,246,0.12)` | AI 浅底 |

> 主题变体（dark-tech / rose-pink）继续通过 JS 动态覆盖这些变量，但整体明暗由 `data-theme` 控制。

#### 4.1.5 状态色（Status）

| Token | 值 | 用途 |
|---|---|---|
| `--success` | `#10B981` | 成功、完成、正向 |
| `--warning` | `#F59E0B` | 警告、风险 |

| `--info` | `#3B82F6` | 提示、信息 |

#### 4.1.6 阴影色（Shadow）

| Token | 深色值 | 浅色值 |
|---|---|---|

### 4.2 间距 Token（Spacing）

基于 4px 网格系统：

| Token | 值 | Tailwind 映射 |
|---|---|---|
| `--space-0` | `0` | - |
| `--space-1` | `4px` | `1` |
| `--space-2` | `8px` | `2` |
| `--space-3` | `12px` | `3` |
| `--space-4` | `16px` | `4` |
| `--space-5` | `20px` | `5` |
| `--space-6` | `24px` | `6` |
| `--space-8` | `32px` | `8` |
| `--space-10` | `40px` | `10` |
| `--space-12` | `48px` | `12` |
| `--space-16` | `64px` | `16` |
| `--space-20` | `80px` | `20` |
| `--space-24` | `96px` | `24` |

使用原则：
- 组件内部间距：4px ~ 16px
- 组件之间间距：16px ~ 24px
- 页面区块间距：24px ~ 48px
- 大区块/页面间距：48px ~ 96px

## 5. 主题实现方案

### 5.1 控制方式

使用 `data-theme` 属性控制整体明暗：

```html
<html data-theme="light">
<html data-theme="dark">
```

### 5.2 CSS 结构

```css
:root {
  /* 默认深色主题 Token */
  --bg-primary: #090B12;
  --bg-card: #111522;
  /* ... 所有深色值 */
}

:root[data-theme='light'] {
  /* 浅色主题覆盖 */
  --bg-primary: #FFFFFF;
  --bg-card: #FFFFFF;
  /* ... */
}
```

### 5.3 与现有主题变体兼容

现有 `dark-tech` / `rose-pink` 是品牌色变体，通过 JS 动态覆盖 `--color-primary` 等变量。v2.7.0 后：

- `data-theme` 控制明暗（light / dark）。
- JS 动态设置控制品牌色变体（保留 dark-tech / rose-pink，未来可扩展）。
- `AppearanceSection` 中的 theme 选项将扩展为：
  - 外观：`light` / `dark` / `system`
  - 品牌变体：`dark-tech` / `rose-pink`（仅 dark 模式下有效）

## 7. 使用规范

### 7.1 颜色使用

| 场景 | 正确做法 | 错误做法 |
|---|---|---|
| 页面背景 | `bg-background` | `bg-[#090B12]` |
| 卡片背景 | `bg-surface` | `bg-[#111522]` |
| 主要文字 | `text-text-primary` | `text-white` |
| 次要文字 | `text-text-secondary` | `text-gray-400` |
| 默认边框 | `border-border-default` | `border-gray-700` |
| 主按钮背景 | `bg-primary` | `bg-[#F43F7A]` |
| 成功状态 | `text-success` | `text-green-500` |

### 7.2 间距使用

优先使用 Tailwind spacing class：

| 场景 | 推荐 class |
|---|---|
| 小间距 | `gap-1`, `gap-2`, `p-2`, `m-2` |
| 中间距 | `gap-4`, `p-4`, `m-4` |
| 大间距 | `gap-6`, `p-6`, `m-6` |
| 页面级 | `p-8`, `gap-8`, `py-12` |

### 7.3 圆角使用

| 场景 | 推荐 class |
|---|---|
| 输入框、小按钮 | `rounded-md` |
| 按钮、小卡片 | `rounded-lg` |
| 卡片、模态框 | `rounded-xl` |
| 大卡片、CommandCard | `rounded-2xl` / `rounded-card` |
| 标签、pills、头像 | `rounded-full` |

## 8. 反模式

以下写法在 v2.7.0 后禁止出现：

```tsx
// ❌ 硬编码颜色
<div className="bg-[#111522]">
<div className="text-white">
<div className="border-gray-700">

// ❌ 使用 Tailwind 默认色板（除非映射到 Token）
<div className="bg-slate-800">
<div className="text-gray-400">

// ❌ 硬编码间距（特殊场景除外）
<div className="p-[13px]">

// ❌ 硬编码阴影
<div className="shadow-[0_4px_20px_rgba(0,0,0,0.3)]">

// ✅ 正确写法
<div className="bg-surface">
<div className="text-text-primary">
<div className="border-border-default">
<div className="p-4 shadow-card">
```
