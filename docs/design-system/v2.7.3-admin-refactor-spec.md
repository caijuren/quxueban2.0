# v2.7.3 Admin 后台重构规范

> 版本：v2.7.3 Admin Refactor  
> 目标：把 Admin 后台做成 Design System 的第一个标杆应用。  
> 状态：规范文档（待实现）

---

## 1. 目标与范围

### 1.1 目标

1. 用 v2.7.1 原子组件和 v2.7.2 分子/布局组件重构 Admin 后台。
2. 建立 Admin 后台的视觉和交互规范。
3. 让 Admin 后台在浅色主题下达到顶尖 SaaS 水准。

### 1.2 范围

- `app/admin/layout.tsx`
- `app/admin/page.tsx`
- `app/admin/users/page.tsx`
- `app/admin/ai-config/page.tsx`

### 1.3 不在范围

- Admin API 改动。
- 新增 Admin 功能页面。
- 非 Admin 页面的改造。

---

## 2. 设计原则

1. **信息密度适中**：Admin 后台需要展示大量数据，但不能拥挤。
2. **操作清晰**：每个页面核心操作不超过 3 个。
3. **反馈及时**：加载、空状态、错误状态统一处理。
4. **响应式**：桌面端为主，移动端基本可用。

---

## 3. 整体布局规范

### 3.1 页面骨架

使用 `AppShell` 组件：

```tsx
<AppShell
  title="趣学伴管理平台"
  navItems={[
    { href: '/admin', icon: LayoutDashboard, label: '概览' },
    { href: '/admin/users', icon: Users, label: '用户管理' },
    { href: '/admin/ai-config', icon: Sparkles, label: 'AI 配置' },
  ]}
>
  {children}
</AppShell>
```

### 3.2 导航规范

- 侧边栏宽度：`w-64`（256px）
- 导航项：图标 + 文字，hover 背景变化。
- 当前项：左侧主色竖线 + 主色文字。
- 顶部 Header：页面标题 + 用户菜单 + 返回前台链接。

### 3.3 内容区

- 内边距：`p-6 lg:p-8`
- 最大宽度：`max-w-7xl`
- 页面标题区：标题 + 描述 + 操作按钮。

## 4. 各页面重构规范

### 4.1 概览页（`/admin`）

#### 页面结构

```
PageHeader
├── 标题：数据概览
├── 描述：平台核心指标一览
└── 操作区：导出报告按钮（可选）

ContentGrid (columns=4)
├── StatCard × 4
│   ├── 注册用户
│   ├── 孩子档案
│   ├── 升学计划
│   └── 周计划

Section
├── 标题：最近用户
├── 操作：查看全部
└── DataTable
```

#### StatCard 指标

| 指标 | 图标 | 颜色 |
|---|---|---|
| 注册用户 | Users | primary |
| 孩子档案 | Baby | secondary |
| 升学计划 | Map | info |
| 周计划 | CalendarCheck | success |

> 不使用硬编码渐变，统一用图标颜色 `text-primary` / `text-secondary` / `text-info` / `text-success`。

#### 最近用户表格

| 列 | 说明 |
|---|---|
| 用户名 | 主文字 |
| 角色 | Badge（管理员 primary，家长 default） |
| 孩子 | 数字 |
| 计划 | 数字 |
| 周计划 | 数字 |
| 注册时间 | 次要文字 |

---

### 4.2 用户管理页（`/admin/users`）

#### 页面结构

```
PageHeader
├── 标题：用户管理
├── 描述：查看平台注册用户及其数据
└── 操作区：无

Card
├── SearchInput
└── DataTable
```

#### 搜索规范

- 搜索框放在表格上方，宽度 `max-w-md`。
- 支持按用户名、姓名过滤。
- 输入时实时过滤（前端过滤）。

#### 表格列

| 列 | 说明 |
|---|---|
| 用户名 | 主文字 + 用户名小字 |
| 角色 | Badge |
| 孩子 | 数字 |
| 计划 | 数字 |
| 周计划 | 数字 |
| 注册时间 | 次要文字 |

#### 空状态

- 搜索无结果时显示 `EmptyState`：
  - icon: Search
  - title: 没有找到用户
  - description: 请尝试其他搜索条件

---

### 4.3 AI 配置页（`/admin/ai-config`）

#### 页面结构

```
PageHeader
├── 标题：AI 配置
├── 描述：配置平台 AI 服务参数
└── 操作区：保存按钮

Card
├── FormField × N
│   ├── 服务提供商 Select
│   ├── API Key Input
│   ├── 模型 Select
│   └── 其他参数
└── 测试连接按钮 + 状态
```

#### 表单规范

- 使用 `FormField` 包装每个表单项。
- 标签右对齐或顶部对齐（统一顶部对齐）。
- 必填项标记红色星号。
- 错误信息统一显示在输入框下方。

#### API Key 输入

- type="password"
- 显示加密提示文字。

#### 测试连接

- 按钮：secondary variant。
- 测试成功：显示 success Alert。
- 测试失败：显示 error Alert。

## 6. 视觉规范

### 6.1 浅色主题下的 Admin

Admin 后台在 v2.7.3 阶段开始默认使用浅色主题：

- 页面背景：`#FFFFFF`
- 侧边栏背景：`#F8FAFC`
- 卡片背景：`#FFFFFF`
- 边框：`rgba(0,0,0,0.08)`
- 主按钮：`#F43F7A`
- 文字主色：`#111827`

### 6.2 深色主题兼容

虽然 Admin 默认浅色，但仍需保证深色主题下可正常显示。

## 7. 响应式规范

| 断点 | 布局 |
|---|---|
| `lg` 及以上 | 侧边栏固定，内容区左侧 256px 偏移 |
| `md` ~ `lg` | 侧边栏隐藏，Header 显示汉堡菜单 |
| `sm` 及以下 | 单列布局，表格横向滚动 |

---

## 8. 空状态与错误状态

### 8.1 加载状态

- 整页加载：居中 `Spinner`。
- 表格加载：`DataTable` 内部 Skeleton。
- 卡片加载：`Skeleton` 占位。

### 8.2 错误状态

- 页面级错误：显示 `Alert` + 重试按钮。
- 表格错误：`DataTable` 空状态显示错误信息。

### 8.3 空状态

- 表格无数据：`EmptyState`。
- 搜索无结果：`EmptyState` + 清除搜索按钮。
