# 趣学伴 Design System v2.8.4 — 数据可视化与状态设计

> 版本：v2.8.4
> 目标：让数据展示更专业、更易读、更有品牌感；统一空状态、加载态、错误态，全面提升产品质感。

---

## 1. 背景

v2.8.3 已完成图标与字体升级。当前数据展示和状态反馈仍存在以下问题：

- 首页、成长报告等页面的数据卡片视觉风格不统一
- 完成率圆环、进度条样式各异，品牌感弱
- 趋势图 tooltip、轴线、网格样式未统一
- 空状态简陋，部分页面直接显示"暂无数据"文字
- 加载态多为粗暴的"加载中"文字或样式不统一的 spinner
- 错误态缺少统一组件，不同页面提示风格不同

v2.8.4 将封装一套数据可视化组件和状态组件。

---

## 2. 设计原则

1. **数据即品牌**：图表、进度、指标统一使用品牌色和 Design Token。
2. **减少认知负担**：大数字 + 趋势 + 标签，一眼获取关键信息。
3. **状态即体验**：空/加载/错误状态不敷衍，保持品牌一致性。
4. **暗色/浅色自适应**：所有图表和状态组件自动适配主题。

---

## 3. 数据可视化组件

### 3.1 `MetricCard`

- 功能：大数字 + 趋势箭头 + 标签
- 支持 `label`、`value`、`trend`（上升/下降/持平）、`suffix`、`prefix`
- 支持 `variant：default / glass / ai`
- 支持 `countUp` 数字增长动画
- 支持 `icon` 在标题左侧

```tsx
<MetricCard
  label="本周完成率"
  value={87}
  suffix="%"
  trend="up"
  trendValue={12}
  variant="glass"
  countUp
/>
```

### 3.2 `ProgressRing`

- 功能：环形进度展示
- 默认内半径 85%，线宽 8px
- 颜色使用 `primary → secondary` 渐变
- 支持尺寸 `sm / md / lg / xl`
- 支持中间显示数字或图标
- 支持动画过渡

### 3.3 `ProgressBar`

- 功能：线性进度条
- 高度 6px，圆角 999px
- 支持 `size：sm / md / lg`
- 支持单色或渐变
- 支持动画过渡（已在 v2.8.2 `motion/progress-bar.tsx` 中实现，本阶段完善样式）

### 3.4 `TrendChart`

- 功能：趋势折线/柱状图
- 基于现有图表库封装（不重复造轮子）
- 统一 tooltip：glass 风格，带阴影
- 统一网格线：`border-subtle`，1px
- 坐标轴文字：`text-caption`，`text-tertiary`
- 折线点 4px，柱状图顶部圆角 4px
- 支持深色/浅色自动适配

### 3.5 `Heatmap`

- 功能：打卡热力图
- 统一颜色梯度：`empty → primary/30 → primary/60 → primary`
- 支持周/月视图
- 支持空状态提示

## 4. 状态组件

### 4.1 `EmptyState`

- 功能：统一空状态
- 支持预设场景：`no-data`、`no-children`、`no-tasks`、`no-plans`、`search-empty`
- 结构：图标/插画 + 标题 + 描述 + 操作按钮
- 支持 `size：sm / md / lg`
- 图标使用 `Icon` 组件，尺寸根据 size 自动映射

```tsx
<EmptyState
  scene="no-children"
  size="md"
  action={{ label: "添加孩子", onClick: () => {} }}
/>
```

### 4.2 `Skeleton`

- 功能：加载占位
- 支持 `variant：default / glass`
- 支持 `animation：pulse / shimmer`
- 支持常见形状：`text`、`circular`、`rectangular`、`rounded`
- 可与卡片结合使用

### 4.3 `ErrorState`

- 功能：统一错误反馈
- 支持预设类型：`403`、`404`、`500`、`network`、`generic`
- 结构：错误图标 + 错误信息 + 重试按钮
- 支持 `retry` 回调

```tsx
<ErrorState type="network" onRetry={() => refetch()} />
```

## 5. 数据可视化规范

### 5.1 色彩语义

| 语义 | Token | 使用场景 |
|---|---|---|
| 主数据 | `primary` 或 `primary → secondary` 渐变 | 完成率、趋势主线 |
| 辅助数据 | `secondary` | 对比数据、辅助指标 |
| 成功/完成 | `success` | 已完成任务、达标 |
| 警告/滞后 | `warning` | 落后进度、待关注 |
| 错误/风险 | `error` | 失败、异常 |
| 中性/背景 | `border-subtle` | 网格线、轴线 |

### 5.2 图表样式

- 网格线：`border-subtle`，1px
- 坐标轴文字：`text-caption`，`text-tertiary`
- Tooltip：`glass` 风格，带阴影
- 圆角：折线点 4px，柱状图顶部圆角 4px

### 5.3 进度展示

- 完成率圆环：内半径 85%，线宽 8px
- 进度条：高度 6px，圆角 999px
- 关键数字：使用 `MetricCard` + `CountUp` 动画

## 6. 页面应用计划

### 6.1 首页 `/dashboard`

- 数据摘要卡使用 `MetricCard` + `CountUp`
- 完成率使用 `ProgressRing`
- 趋势图使用 `TrendChart`

### 6.2 成长报告 `/dashboard/reports`

- 报告头部核心指标使用 `MetricCard` 组合
- 学科分析使用 `ProgressBar` 展示各科目完成率
- 周打卡热力图使用 `Heatmap`
- 趋势图使用 `TrendChart`

### 6.3 今日任务 `/dashboard/today`

- 任务列表加载使用 `Skeleton`
- 无任务状态使用 `EmptyState scene="no-tasks"`

### 6.4 周计划 `/dashboard/weekly`

- 计划加载使用 `Skeleton`
- 无计划状态使用 `EmptyState scene="no-plans"`

### 6.5 设置中心 `/dashboard/settings/*`

- 数据加载使用 `Skeleton`
- 错误状态使用 `ErrorState`

## 8. 技术实现要点

### 8.1 图表库选择

- 若项目已有图表库，继续封装使用
- 若没有，优先选择轻量级库（如 `recharts`）
- 禁止在业务页面直接写复杂 chart 配置

### 8.2 暗色/浅色适配

- 图表颜色通过 CSS variables 读取
- Tooltip 背景使用 `glass` 工具类
- 坐标轴文字使用 `text-tertiary`

### 8.3 性能

- 大数据量图表使用虚拟化或采样
- 动画仅使用 `transform` 和 `opacity`

## 10. 风险与应对

| 风险 | 影响 | 应对策略 |
|---|---|---|
| 图表库引入增加包体积 | 首屏加载变慢 | 选择轻量库，按需加载 |
| 暗色/浅色图表适配复杂 | 视觉不一致 | 统一通过 CSS variables 读取颜色 |
| 空状态插画风格不统一 | 品牌感弱 | 使用 Icon + 统一文案，暂不引入大量插画 |
| 旧加载态替换不完全 | 体验不统一 | 全局搜索"加载中"等文案逐个替换 |
