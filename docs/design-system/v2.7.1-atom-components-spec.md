# v2.7.1 原子组件规范

> 版本：v2.7.1 Atoms  
> 目标：建立最基础的 UI 积木，统一按钮、输入框、标签、卡片等原子级组件。  
> 状态：规范文档（待实现）

---

## 1. 目标与范围

### 1.1 目标

1. 为项目提供一套统一的原子组件库。
2. 所有原子组件必须使用 v2.7.0 定义的 Design Token。
3. 所有原子组件必须支持深色/浅色双主题。
4. 降低后续页面开发和维护成本。

### 1.2 范围

- 组件位置：`components/ui/`。
- 覆盖组件：Button、Input、Textarea、Select、Badge、Card、Avatar、Spinner、Skeleton、Switch、Checkbox、Radio、Tooltip、Divider。
- 不覆盖：业务组件、布局组件（在 v2.7.2 中定义）。

### 1.3 不在范围

- 复杂表单逻辑（如表单校验、联动）在分子组件 FormField 中处理。
- 数据表格在 DataTable 分子组件中处理。
- 模态框基于现有 Modal 组件升级。

---

## 2. 设计原则

1. **单一职责**：每个组件只做一件事，但把这件事做好。
2. **组合优先**：通过 props 组合变体，不造新组件。
3. **可扩展**：所有组件支持 `className` 扩展和 ref 转发。
4. **主题无关**：组件代码不感知当前是深色还是浅色，只使用 Token。
5. **状态完整**：必须处理 default、hover、focus、active、disabled、loading、error 等状态。

## 4. 通用规范

所有原子组件必须满足：

### 4.1 文件模板

```tsx
'use client';

import * as React from 'react';
import { cn } from '@/lib/utils';

export interface XxxProps extends React.XXXAttributes<HTMLElement> {
  // 组件特定 props
  className?: string;
}

const Xxx = React.forwardRef<HTMLElement, XxxProps>(
  ({ className, ...props }, ref) => {
    return (
      <element
        ref={ref}
        className={cn(
          // base styles
          className
        )}
        {...props}
      />
    );
  }
);
Xxx.displayName = 'Xxx';

export default Xxx;
```

### 4.2 必须支持的 props

- `className?: string` — 允许外部扩展样式。
- 交互组件必须支持 ref 转发。

### 4.3 禁止使用

- 硬编码颜色。
- 硬编码阴影、圆角、字号（特殊情况需文档说明）。
- 业务逻辑耦合。

### 4.4 状态样式统一

| 状态 | 处理方式 |
|---|---|
| hover | `hover:` 前缀 |
| focus | `focus-visible:` 前缀，统一 ring |
| active | `active:` 前缀 |
| disabled | `disabled:` 前缀或 `aria-disabled` |
| loading | 由组件内部处理，不响应交互 |
| error | 边框变 `--border-error` 或 `--error` |

## 5. 组件详细规范

### 5.1 Button

#### 用途

触发操作或事件。

#### Props

```ts
export interface ButtonProps
  extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'primary' | 'secondary' | 'ghost' | 'danger' | 'link';
  size?: 'xs' | 'sm' | 'md' | 'lg';
  isLoading?: boolean;
  leftIcon?: React.ReactNode;
  rightIcon?: React.ReactNode;
}
```

#### 变体样式

| variant | 默认背景 | 文字色 | hover | border |
|---|---|---|---|---|
| primary | `bg-primary` | `text-text-primary` | `hover:bg-primary/90` | 无 |
| secondary | `bg-surface` | `text-text-secondary` | `hover:bg-surface-hover` | `border-border-default` |
| ghost | transparent | `text-text-secondary` | `hover:bg-surface-hover hover:text-text-primary` | 无 |
| danger | `bg-error/10` | `text-error` | `hover:bg-error/20` | 无 |
| link | transparent | `text-primary` | `hover:underline` | 无 |

#### 尺寸

| size | height | padding | font-size |
|---|---|---|---|
| xs | `h-7` | `px-2.5` | `text-xs` |
| sm | `h-8` | `px-3` | `text-xs` |
| md | `h-10` | `px-4` | `text-sm` |
| lg | `h-12` | `px-6` | `text-base` |

#### 公共样式

```tsx
'inline-flex items-center justify-center gap-2 rounded-lg font-medium',
'transition-colors duration-fast focus-visible:outline-none focus-visible:ring-2',
'focus-visible:ring-primary/50 focus-visible:ring-offset-2 focus-visible:ring-offset-background',
'disabled:pointer-events-none disabled:opacity-60',
```

#### loading 状态

- `isLoading=true` 时显示左侧 Spinner，文字保留但降低透明度。
- 按钮进入 `cursor-wait`，不响应点击。

#### 使用示例

```tsx
<Button variant="primary" size="md">保存</Button>
<Button variant="secondary" leftIcon={<Plus />}>新增</Button>
<Button variant="danger" size="sm">删除</Button>
<Button isLoading>提交中</Button>
```

### 5.2 Input

#### 用途

单行文本输入。

#### Props

```ts
export interface InputProps
  extends React.InputHTMLAttributes<HTMLInputElement> {
  size?: 'sm' | 'md' | 'lg';
  error?: boolean;
  helperText?: string;
  leftIcon?: React.ReactNode;
  rightIcon?: React.ReactNode;
}
```

#### 基础样式

```tsx
'w-full rounded-lg border bg-surface text-text-primary placeholder:text-text-muted',
'transition-colors duration-fast',
'focus:border-primary focus:outline-none focus:ring-2 focus:ring-primary/10',
'disabled:cursor-not-allowed disabled:opacity-60 disabled:bg-bg-disabled',
```

#### 尺寸

| size | height | padding | font-size |
|---|---|---|---|
| sm | `h-8` | `px-3` | `text-xs` |
| md | `h-10` | `px-4` | `text-sm` |
| lg | `h-12` | `px-4` | `text-base` |

#### error 状态

- 边框：`border-error focus:border-error focus:ring-error/10`
- 可选：左侧或右侧显示 error icon。

#### leftIcon / rightIcon

- 图标容器绝对定位在 input 内部。
- 有 leftIcon 时，input 左 padding 增加。
- 有 rightIcon 时，input 右 padding 增加。

#### 使用示例

```tsx
<Input placeholder="请输入用户名" />
<Input size="sm" leftIcon={<Search />} placeholder="搜索..." />
<Input error helperText="用户名不能为空" />
```

### 5.3 Textarea

#### 用途

多行文本输入。

#### Props

```ts
export interface TextareaProps
  extends React.TextareaHTMLAttributes<HTMLTextAreaElement> {
  error?: boolean;
  maxLength?: number;
  showCount?: boolean;
  resize?: 'none' | 'vertical' | 'horizontal' | 'both';
}
```

#### 基础样式

```tsx
'w-full min-h-[80px] rounded-lg border border-border-default bg-surface p-3 text-sm text-text-primary placeholder:text-text-muted',
'transition-colors duration-fast',
'focus:border-primary focus:outline-none focus:ring-2 focus:ring-primary/10',
'disabled:cursor-not-allowed disabled:opacity-60 disabled:bg-bg-disabled',
```

#### 字数统计

- `showCount=true` 时，在右下角显示 `当前字数 / maxLength`。
- 超过 maxLength 时数字变 `text-error`。

#### 使用示例

```tsx
<Textarea placeholder="请输入备注" />
<Textarea maxLength={200} showCount resize="vertical" />
```

### 5.4 Select

#### 用途

下拉选择。

#### Props

```ts
export interface SelectOption {
  value: string;
  label: string;
  disabled?: boolean;
}

export interface SelectProps
  extends React.SelectHTMLAttributes<HTMLSelectElement> {
  options: SelectOption[];
  size?: 'sm' | 'md' | 'lg';
  error?: boolean;
  placeholder?: string;
}
```

#### 基础样式

```tsx
'w-full appearance-none rounded-lg border border-border-default bg-surface px-4 pr-10 text-sm text-text-primary',
'transition-colors duration-fast',
'focus:border-primary focus:outline-none focus:ring-2 focus:ring-primary/10',
'disabled:cursor-not-allowed disabled:opacity-60 disabled:bg-bg-disabled',
```

#### 右侧箭头

- 使用绝对定位的 `ChevronDown` 图标。
- 图标颜色：`text-text-muted`。

#### 使用示例

```tsx
<Select
  options={[
    { value: 'admin', label: '管理员' },
    { value: 'parent', label: '家长' },
  ]}
/>
```

> 复杂 Select（可搜索、多选）后续在 v2.7.2 作为分子组件实现，原子组件阶段只实现原生 select 封装。

### 5.6 Card

#### 用途

内容容器。

#### Props

```ts
export interface CardProps extends React.HTMLAttributes<HTMLDivElement> {
  padding?: 'none' | 'sm' | 'md' | 'lg';
  radius?: 'md' | 'lg' | 'xl' | '2xl';
  shadow?: 'none' | 'sm' | 'md' | 'lg' | 'card';
  border?: boolean;
  hover?: boolean;
}
```

#### 基础样式

```tsx
'bg-surface transition-all duration-fast',
```

#### 变体

| prop | 默认值 | 可选值 |
|---|---|---|
| padding | `md` | none / sm / md / lg |
| radius | `xl` | md / lg / xl / 2xl |
| shadow | `sm` | none / sm / md / lg / card |
| border | `true` | boolean |
| hover | `false` | boolean |

#### hover 效果

- `hover=true` 时：`hover:border-border-strong hover:bg-surface-hover`。

#### 使用示例

```tsx
<Card>
  <Card.Header title="标题" description="描述" />
  <Card.Body>内容</Card.Body>
</Card>

<Card padding="sm" hover>
  可点击卡片
</Card>
```

> Card 可拆分为 `Card`、`Card.Header`、`Card.Body`、`Card.Footer` 子组件，通过 `Card` 命名空间导出。

### 5.7 Avatar

#### 用途

用户/孩子头像展示。

#### Props

```ts
export interface AvatarProps extends React.HTMLAttributes<HTMLDivElement> {
  src?: string | null;
  name?: string | null;
  size?: 'xs' | 'sm' | 'md' | 'lg' | 'xl';
  shape?: 'circle' | 'square';
}
```

#### 尺寸

| size | size 值 |
|---|---|
| xs | `w-6 h-6` |
| sm | `w-8 h-8` |
| md | `w-10 h-10` |
| lg | `w-12 h-12` |
| xl | `w-16 h-16` |

#### fallback

- 有图片时显示图片。
- 无图片时显示名字首字或默认图标。
- fallback 背景：`bg-surface-hover`，文字：`text-text-secondary`。

#### 使用示例

```tsx
<Avatar src="/avatar.png" name="张三" />
<Avatar name="李四" size="lg" />
<Avatar size="sm" shape="square" />
```

### 5.10 Switch

#### 用途

开关切换。

#### Props

```ts
export interface SwitchProps
  extends Omit<React.InputHTMLAttributes<HTMLInputElement>, 'size'> {
  size?: 'sm' | 'md';
  checked?: boolean;

}
```

#### 基础样式

```tsx
'relative inline-flex cursor-pointer items-center rounded-full transition-colors duration-fast',
'focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-primary/50',
'disabled:cursor-not-allowed disabled:opacity-60',
```

#### 尺寸

| size | track | thumb |
|---|---|---|
| sm | `w-9 h-5` | `w-4 h-4` |
| md | `w-11 h-6` | `w-5 h-5` |

#### 状态

- checked：`bg-primary`
- unchecked：`bg-surface-highlight` 或 `bg-bg-disabled`

#### 使用示例

```tsx
<Switch checked={enabled} onCheckedChange={setEnabled} />
```

### 5.13 Tooltip

#### 用途

鼠标悬停提示。

#### Props

```ts
export interface TooltipProps {
  children: React.ReactElement;
  content: React.ReactNode;
  placement?: 'top' | 'bottom' | 'left' | 'right';
  delay?: number;
}
```

#### 基础样式

```tsx
'z-tooltip rounded-lg border border-border-default bg-surface-elevated px-3 py-1.5 text-xs text-text-secondary shadow-lg',
```

#### 行为

- hover 后延迟 `delay`（默认 200ms）显示。
- 鼠标移出后消失。
- 支持四个方向定位。

#### 使用示例

```tsx
<Tooltip content="删除此项目">
  <Button variant="ghost" size="sm">删除</Button>
</Tooltip>
```
