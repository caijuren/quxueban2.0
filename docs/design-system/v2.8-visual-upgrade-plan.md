# 趣学伴 Design System v2.8 视觉升级方案

> 版本：v2.8.0 ~ v2.8.5
> 目标：在 v2.7 Design System 基础上，引入 Apple Liquid Glass 视觉语言、全局动效系统、统一图标与字体，打造更具高级感与辨识度的家庭教育执行系统。
> 原则：**先定义视觉语言与 Token，再改造组件，最后落地页面；每个小版本独立可发布。**

---

## 1. 背景与目标

### 1.1 当前状态

v2.7.x 已经完成了 Design System 2.0 的基础建设：

- 完整的深色/浅色 Design Token 体系
- 原子、分子、布局三层组件库
- Admin 后台与家长端统一使用 Token 和组件
- 浅色主题已上线，支持 light / dark / system 切换
- 硬编码颜色与样式已全面清理

### 1.2 仍存在的问题

- 界面整体偏"静"，缺少有品质感的微动效
- 卡片仍以实色为主，缺少 Liquid Glass 的通透与层次
- 图标风格偶有混杂，部分业务场景缺少专属图标
- 数据可视化（仪表盘、完成率、趋势图）视觉语言不统一
- 空状态、加载态、错误态偏简陋，影响产品质感
- 移动端部分页面信息密度过高，交互区域偏小

### 1.3 升级目标

1. **视觉升级**：引入 Apple Liquid Glass 设计语言，提升高端感与科技感。
2. **动效升级**：建立全局动效系统，让界面有响应、有节奏、不拖沓。
3. **品牌升级**：统一图标、字体、插画，强化"趣学伴"家庭教育品牌识别。
4. **数据可视化升级**：图表、进度、指标统一风格，数据更易读。
5. **细节打磨**：空状态、加载态、错误态、移动端适配全面提升。

## 2. 设计愿景

### 2.1 一句话定义

> **"清晰、温暖、有未来感的家庭教育控制中心。"**

### 2.2 三个关键词

| 关键词 | 含义 | 落地方式 |
|---|---|---|
| **清晰** | 信息层级明确，一眼能找到重点 | 大字号标题、充足留白、统一色彩语义 |
| **温暖** | 家庭教育产品，不能太冷硬 | 柔和圆角、玫瑰红主色、亲子向插画 |
| **未来感** | 科技感但不冰冷 | Liquid Glass 卡片、 subtle 光效、流畅动效 |

### 2.3 Liquid Glass 应用原则

- **深色模式**：玻璃效果最明显，可用在首页 Hero、成长报告、AI 模块、设置头部
- **浅色模式**：玻璃效果更清透，主要用于顶部栏、浮动面板、高价值卡片
- **内容密集区**：表格、任务列表、设置表单继续用实色卡片，保证可读性
- **禁止滥用**：同一屏幕玻璃卡片不超过 3 个，避免视觉混乱

## 4. 各阶段详细说明

### v2.8.0 Liquid Glass Foundation

**目标**：让"玻璃质感"成为系统能力，任何组件/页面可以一键启用。

**怎么做**：

1. 扩展 `globals.css`，新增 Glass 相关 Token：
   - `--glass-bg`: 玻璃背景色（深色/浅色不同）
   - `--glass-border`: 玻璃边框色
   - `--glass-highlight`: 玻璃顶部高光
   - `--glass-shadow`: 玻璃投影
   - `--glass-blur`: blur 半径
2. 新增工具类：
   - `.glass`：标准玻璃卡片
   - `.glass-strong`：强玻璃效果（用于 Hero、核心数据卡）
   - `.glass-subtle`：弱玻璃效果（用于浮动面板、下拉菜单）
   - `.glass-border`：玻璃边框
   - `.glass-shine`：顶部高光效果
3. 新增 `GlassCard` 组件：
   - 支持 `strength: 'subtle' | 'default' | 'strong'`
   - 支持 `hover` 抬升效果
   - 支持 `glow` 光晕（primary / secondary / ai）
   - 支持深色/浅色自动适配
4. 扩展 `tailwind.config.ts`：
   - `backdrop-blur-glass`
   - `bg-glass`
   - `border-glass`
   - `shadow-glass`
5. 建立 Glass 使用规范文档。

**交付物**：

- `docs/design-system/v2.8.0-glass-spec.md`
- 更新后的 `app/globals.css`
- 更新后的 `tailwind.config.ts`
- 新增 `components/ui/glass-card.tsx`

**验收标准**：

- [ ] 深色/浅色主题下 Glass 卡片都能正确渲染
- [ ] GlassCard 组件支持所有文档中声明的变体

### v2.8.2 全局动效系统

**目标**：让界面"活"起来，但保持克制和专业。

**怎么做**：

1. 扩展 Motion Token：
   - `--duration-entrance: 400ms`
   - `--duration-layout: 300ms`
   - `--duration-hover: 150ms`
   - `--ease-entrance: cubic-bezier(0.16, 1, 0.3, 1)`
   - `--ease-layout: cubic-bezier(0.4, 0, 0.2, 1)`
   - `--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1)`
2. 建立动效组件：
   - `FadeIn`：淡入
   - `SlideUp`：上滑淡入
   - `StaggerContainer` / `StaggerItem`：错落入场
   - `ScaleOnHover`：悬停缩放
   - `CountUp`：数字增长动画
   - `ProgressBar`：进度条平滑过渡
3. 全局动效规则：
   - 页面首次加载：内容 stagger 入场，间隔 50ms
   - 卡片悬停：translateY(-2px) + shadow 扩散，150ms
   - 按钮点击：scale(0.98)，100ms
   - 主题切换：颜色过渡 300ms，避免闪烁
   - 模态框：scale(0.96) → scale(1) + opacity，200ms
4. 提供 `useReducedMotion` 支持，尊重系统设置。

**交付物**：

- `docs/design-system/v2.8.2-motion-spec.md`
- 新增 `components/motion/*` 组件
- 更新 `components/ui/button.tsx` 等基础组件支持动效

**验收标准**：

- [ ] 首页、成长报告、AI 页面有 stagger 入场效果
- [ ] 所有卡片/按钮悬停有统一反馈
- [ ] 开启系统"减少动态效果"后，所有动画自动禁用
- [ ] 动效不导致页面掉帧（60fps）

## 5. Liquid Glass 2.0 设计规范

### 5.1 Glass 三档强度

| 强度 | 使用场景 | backdrop-filter | 背景透明度 | 边框 |
|---|---|---|---|---|
| **Subtle** | 下拉菜单、浮动面板、提示框 | blur(12px) | 40% | 1px rgba 白/黑 8% |
| **Default** | 普通卡片、侧边栏、设置项 | blur(20px) | 55% | 1px rgba 白/黑 10% |
| **Strong** | 首页 Hero、核心数据卡、报告头部 | blur(32px) | 70% | 1px rgba 白/黑 12% |

### 5.2 玻璃高光

- 顶部 1px 高光：`rgba(255, 255, 255, 0.08)`（深色） / `rgba(255, 255, 255, 0.4)`（浅色）
- 底部 1px 弱阴影：`rgba(0, 0, 0, 0.1)`（深色） / `rgba(0, 0, 0, 0.04)`（浅色）

### 5.3 Glow 光晕

- **Primary Glow**：`0 0 40px rgba(244, 63, 122, 0.15)`
- **Secondary Glow**：`0 0 40px rgba(139, 92, 246, 0.15)`
- **AI Glow**：同 Secondary Glow
- 仅用于核心卡片，同一页面不超过 1 个

### 5.4 可读性保障

- Glass 背景上的文字必须叠加一层 subtle 遮罩或选择对比度足够的背景
- 正文在 Glass 上对比度 ≥ 4.5:1
- 大标题在 Glass 上对比度 ≥ 3:1

## 6. 动效系统规范

### 6.1 动效层次

| 层级 | 场景 | 时长 | 缓动 |
|---|---|---|---|
| **Micro** | 按钮点击、图标切换、开关 | 100ms | ease-out |
| **Standard** | 悬停、卡片展开、下拉菜单 | 150ms | ease-in-out |
| **Entrance** | 页面加载、模态框出现 | 300~400ms | ease-entrance |
| **Layout** | 列表排序、路由切换、主题切换 | 300ms | ease-layout |

### 6.2 入场动画模式

- 页面内容使用 `SlideUp` + `FadeIn`
- 卡片组使用 `StaggerContainer`，子元素间隔 50ms
- Hero 区域元素间隔 80ms
- 避免所有元素同时运动

### 6.3 悬停与反馈

- 卡片：`translateY(-2px)` + `shadow-lg` → `shadow-xl`
- 按钮：`scale(0.98)` 点击反馈
- 链接：颜色过渡 + 下划线展开
- 禁用态：无悬停效果，cursor-not-allowed

### 6.4 性能要求

- 所有动画仅使用 `transform` 和 `opacity`
- 避免动画 `width`、`height`、`top`、`left`
- 使用 `will-change` 谨慎，动画结束后移除
- 支持 `prefers-reduced-motion`

## 7. 图标与字体规范

### 7.1 图标尺寸规范

| 尺寸 | 像素 | 使用场景 |
|---|---|---|
| xs | 12px | 内联小标签、Badge 内 |
| sm | 16px | 按钮、表单提示 |
| md | 20px | 导航、列表项 |
| lg | 24px | 空状态、操作按钮 |
| xl | 32px | Hero 区域、功能入口 |

### 7.2 图标颜色规范

- 默认：`text-secondary`
- 激活：`text-primary`
- 禁用：`text-disabled`
- 警告：`text-warning`
- 错误：`text-error`
- 成功：`text-success`

### 7.3 字体层级

| Token | 尺寸 | 字重 | 行高 | 使用场景 |
|---|---|---|---|---|
| display | 2.25rem | bold | 1.2 | 首页大标题、报告总分 |
| h1 | 1.875rem | semibold | 1.25 | 页面标题 |
| h2 | 1.5rem | semibold | 1.3 | 区块标题 |
| h3 | 1.25rem | medium | 1.4 | 卡片标题 |
| body | 1rem | normal | 1.6 | 正文 |
| caption | 0.875rem | normal | 1.5 | 辅助说明 |
| micro | 0.75rem | medium | 1.4 | 标签、时间 |

## 8. 数据可视化规范

### 8.1 色彩语义

- 主数据：`primary` 或 `primary → secondary` 渐变
- 辅助数据：`secondary`
- 成功/完成：`success`
- 警告/滞后：`warning`
- 错误/风险：`error`
- 中性/背景：`border-subtle`

### 8.2 图表样式

## 12. 风险与依赖

| 风险 | 影响 | 应对策略 |
|---|---|---|
| Liquid Glass 性能开销 | 低端设备/移动端掉帧 | 提供 `data-reduced-motion` 降级；避免大面积 blur |
| 浅色模式玻璃效果过淡 | 视觉层次丢失 | 浅色下使用更强的边框和阴影补偿 |
| 图标全部替换工作量大 | 工期延长 | 分阶段替换，优先 P0 页面 |
| 动效过度导致用户疲劳 | 体验下降 | 严格遵循动效时长规范，支持 reduced-motion |
| 移动端适配遗漏 | 发布后问题 | 每个子版本都进行移动端检查 |
