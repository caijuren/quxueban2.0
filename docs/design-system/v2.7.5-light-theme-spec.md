# v2.7.5 浅色主题上线规范

> 版本：v2.7.5 Light Theme  
> 目标：正式启用浅色主题，Admin 后台默认浅色，家长端可选深色。  
> 状态：规范文档（待实现）

---

## 1. 目标与范围

### 1.1 目标

1. 完善浅色主题 Token，确保所有组件在浅色下正常显示。
2. Admin 后台默认使用浅色主题。
3. 家长端/控制台保持深色主题，但支持用户手动切换。
4. 主题切换无闪烁、无布局错乱。

### 1.2 范围

- Web 端全局主题切换。
- Admin 后台默认浅色。
- `components/settings/AppearanceSection.tsx` 主题设置升级。

### 1.3 不在范围

- 小程序端主题（小程序保持独立）。
- 自动根据系统主题切换（可选，但需实现）。

---

## 2. 设计原则

1. **默认浅色给 Admin**：Admin 后台面向管理用户，浅色更专业、可信。
2. **默认深色给家长端**：家长端保持现有深色科技风格，符合品牌定位。
3. **切换无感知**：用户切换主题时不能看到闪烁或布局跳变。
4. **持久化**：主题偏好保存到 localStorage 和数据库（用户设置）。

## 4. 主题切换实现

### 4.1 主题类型

```ts
export type Theme = 'light' | 'dark' | 'system';
```

### 4.2 主题工具函数

在 `lib/theme.ts` 中提供：

```ts
export function setTheme(theme: Theme): void;
export function getTheme(): Theme;
export function getResolvedTheme(theme: Theme): 'light' | 'dark';
export function subscribeToSystemTheme(callback: (theme: 'light' | 'dark') => void): () => void;
```

### 4.3 初始化策略

为避免 SSR/CSR 不匹配导致的闪烁：

1. 服务端渲染时，HTML 默认使用 `data-theme="dark"`。
2. 客户端首次渲染前，通过内联脚本读取 localStorage 并设置正确主题。
3. React hydration 后，监听系统主题变化（如果用户选择 system）。

### 4.4 内联脚本

在 `app/layout.tsx` 的 `<head>` 中加入：

```tsx
<script
  dangerouslySetInnerHTML={{
    __html: `
      (function() {
        function getTheme() {
          const saved = localStorage.getItem('theme');
          if (saved === 'light' || saved === 'dark') return saved;
          if (saved === 'system' || !saved) {
            return window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
          }
          return 'dark';
        }
        document.documentElement.setAttribute('data-theme', getTheme());
      })();
    `,
  }}
/>
```

## 5. 路由级默认主题

### 5.1 Admin 默认浅色

在 `app/admin/layout.tsx` 中强制设置浅色主题（可覆盖用户偏好）：

```tsx
useEffect(() => {
  document.documentElement.setAttribute('data-theme', 'light');
  return () => {
    // 离开 Admin 时恢复用户偏好主题
    const saved = localStorage.getItem('theme') as Theme | null;
    setTheme(saved ?? 'dark');
  };
}, []);
```

> 或者更简单：Admin 路由统一使用浅色，不在 Admin 内提供主题切换。

### 5.2 家长端默认深色

家长端/控制台保持 `data-theme="dark"` 作为默认。

## 6. 设置页升级

### 6.1 当前设置

当前 `AppearanceSection` 中 theme 选项：
- `dark-tech`
- `rose-pink`

### 6.2 新设置

升级为两组选项：

**外观主题**
- 浅色
- 深色
- 跟随系统

**深色风格变体**（仅在深色主题下显示）
- 暗黑科技（dark-tech）
- 玫瑰粉（rose-pink）

### 6.3 UI 实现

```tsx
<div className="space-y-4">
  <FormField label="外观主题">
    <div className="grid grid-cols-3 gap-2">
      {['light', 'dark', 'system'].map((t) => (
        <Button
          key={t}
          variant={theme === t ? 'primary' : 'secondary'}
          onClick={() => setTheme(t)}
        >
          {t === 'light' && '浅色'}
          {t === 'dark' && '深色'}
          {t === 'system' && '跟随系统'}
        </Button>
      ))}
    </div>
  </FormField>

  {theme !== 'light' && (
    <FormField label="深色风格">
      <div className="grid grid-cols-2 gap-2">
        {['dark-tech', 'rose-pink'].map((v) => (
          <Button
            key={v}
            variant={variant === v ? 'primary' : 'secondary'}
            onClick={() => setVariant(v)}
          >
            {v === 'dark-tech' ? '暗黑科技' : '玫瑰粉'}
          </Button>
        ))}
      </div>
    </FormField>
  )}
</div>
```
