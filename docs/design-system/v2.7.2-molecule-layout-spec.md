# v2.7.2 分子与布局组件规范

> 版本：v2.7.2 Molecules & Layouts  
> 目标：用原子组件搭建更高层的复用模块和页面骨架。  
> 状态：规范文档（待实现）

---

## 1. 目标与范围

### 1.1 目标

1. 在原子组件基础上，建立可复用的分子组件（业务常用组合）。
2. 建立统一的页面布局组件，规范所有页面骨架。
3. 让 Admin 后台和后续页面能“拼组件”完成。

### 1.2 范围

- 分子组件：`components/ui/`（与原子组件同目录，但复杂度更高）。
- 布局组件：`components/layout/`。
- 依赖：v2.7.1 原子组件库必须完成。

### 1.3 不在范围

- 具体业务页面实现（在 v2.7.3 Admin Refactor 中处理）。
- 复杂可视化组件（在 v2.7.4 中处理）。

---

## 2. 设计原则

1. **基于原子组件**：分子组件必须由 v2.7.1 原子组件组合而成，不引入新样式。
2. **布局即约束**：布局组件只负责位置和间距，不控制视觉风格。
3. **可配置**：通过 props 控制常见变体，不过度设计。
4. **响应式**：布局组件必须考虑移动端适配。

---

## 3. 组件清单

### 3.1 分子组件

| 组件 | 用途 | 依赖 |
|---|---|---|
| `FormField` | Label + Input/Select/Textarea + Error + Helper | Input, Select, Textarea |
| `SearchInput` | 带搜索图标的输入框 | Input |
| `StatCard` | 统计数字卡片 | Card, Badge |
| `DataTable` | 数据表格 | Card, Badge, Button, Spinner, Skeleton |
| `EmptyState` | 空状态（升级现有） | Card, Button |
| `ConfirmDialog` | 确认对话框 | Modal, Button |
| `Toast` | 全局通知 | 自定义实现 |
| `Alert` | 页面内提示 | Card |

### 3.2 布局组件

| 组件 | 用途 |
|---|---|
| `AppShell` | 应用外壳：侧边栏 + 顶部 Header + 内容区 |
| `PageHeader` | 页面标题 + 面包屑 + 操作按钮 |
| `PageContainer` | 页面内容容器 |
| `ContentGrid` | 卡片网格布局 |
| `Section` | 带标题的内容区块 |

## 4. 分子组件详细规范

### 4.1 FormField

#### 用途

统一表单字段组合：标签、输入控件、错误信息、辅助文字。

#### Props

```ts
export interface FormFieldProps {
  label?: string;
  required?: boolean;
  error?: string;
  helper?: string;
  children: React.ReactElement;
  className?: string;
}
```

#### 结构

```tsx
<div className="space-y-1.5">
  {label && (
    <label className="text-sm font-medium text-text-secondary">
      {label}
      {required && <span className="text-error ml-0.5">*</span>}
    </label>
  )}
  <div>{children}</div>
  {helper && !error && <p className="text-xs text-text-muted">{helper}</p>}
  {error && <p className="text-xs text-error">{error}</p>}
</div>
```

#### 使用示例

```tsx
<FormField label="用户名" required error={errors.username}>
  <Input placeholder="请输入用户名" />
</FormField>

<FormField label="角色" helper="选择用户角色">
  <Select options={roles} />
</FormField>
```

### 4.2 SearchInput

#### 用途

带搜索图标的输入框，常用于表格、列表过滤。

#### Props

```ts
export interface SearchInputProps
  extends Omit<InputProps, 'leftIcon' | 'type'> {
  onClear?: () => void;
}
```

#### 行为

- 左侧固定 `Search` 图标。
- 有内容时右侧显示 `X` 清除按钮。
- 支持 `onClear` 回调。

#### 使用示例

```tsx
<SearchInput
  placeholder="搜索用户名或姓名"
  value={query}
  onChange={(e) => setQuery(e.target.value)}
  onClear={() => setQuery('')}
/>
```

### 4.3 StatCard

#### 用途

Dashboard 统计卡片。

#### Props

```ts
export interface StatCardProps {
  title: string;
  value: string | number;
  icon?: LucideIcon;
  trend?: {
    value: number;
    isPositive: boolean;
  };
  loading?: boolean;
  className?: string;
}
```

#### 结构

```tsx
<Card padding="md">
  <div className="flex items-start justify-between">
    <div>
      <p className="text-sm text-text-secondary">{title}</p>
      <p className="mt-1 text-2xl font-bold text-text-primary">{value}</p>
      {trend && <TrendBadge trend={trend} />}
    </div>
    {icon && (
      <div className="rounded-lg bg-primary/10 p-2 text-primary">
        <Icon className="h-5 w-5" />
      </div>
    )}
  </div>
</Card>
```

#### 使用示例

```tsx
<StatCard
  title="注册用户"
  value={1234}
  icon={Users}
  trend={{ value: 12, isPositive: true }}
/>
```

### 4.4 DataTable

#### 用途

统一数据表格，替代各页面自行实现的 `<table>`。

#### Props

```ts
export interface DataTableColumn<T> {
  key: string;
  title: string;
  width?: string;
  align?: 'left' | 'center' | 'right';
  render?: (row: T, index: number) => React.ReactNode;
  sorter?: (a: T, b: T) => number;
}

export interface DataTableProps<T> {
  columns: DataTableColumn<T>[];
  data: T[];
  loading?: boolean;
  emptyText?: string;
  rowKey?: keyof T | ((row: T) => string);
  pagination?: {
    current: number;
    pageSize: number;
    total: number;
    onChange: (page: number) => void;
  };
  onRowClick?: (row: T) => void;
  className?: string;
}
```

#### 基础样式

- 表头：`bg-surface-hover text-text-muted text-xs font-medium uppercase tracking-wide`
- 行：`text-text-secondary hover:bg-surface-hover`
- 单元格 padding：`px-6 py-4`
- 边框：只保留底部分隔线 `border-b border-border-subtle`

#### 功能

- 排序：点击表头触发，显示升序/降序图标。
- 分页：底部分页器。
- 空状态：显示 `EmptyState` 或简单文字。
- 加载态：显示 `Skeleton` 行。
- 行点击：`onRowClick` 存在时行可点击，hover 背景变化。

#### 使用示例

```tsx
<DataTable
  columns={[
    { key: 'name', title: '用户名', render: (u) => u.name },
    { key: 'role', title: '角色', render: (u) => <Badge>{u.role}</Badge> },
    { key: 'createdAt', title: '注册时间', render: (u) => formatDate(u.createdAt) },
  ]}
  data={users}
  pagination={{ current: 1, pageSize: 10, total: 100, onChange: setPage }}
/>
```

### 4.5 EmptyState

#### 用途

空列表、无搜索结果、无数据时的统一提示。

#### Props

```ts
export interface EmptyStateProps {
  icon?: LucideIcon;
  title: string;
  description?: string;
  action?: {
    label: string;
    onClick: () => void;
  };
  compact?: boolean;
}
```

#### 结构

```tsx
<div className="flex flex-col items-center justify-center text-center">
  {icon && (
    <div className="rounded-full bg-surface-hover p-3 text-text-tertiary">
      <Icon className="h-6 w-6" />
    </div>
  )}
  <p className="mt-4 font-medium text-text-secondary">{title}</p>
  {description && <p className="mt-1 text-sm text-text-muted">{description}</p>}
  {action && <Button className="mt-4">{action.label}</Button>}
</div>
```

#### 变体

- `compact=true`：用于表格内部、小空间。
- `compact=false`：用于页面级空状态。

#### 使用示例

```tsx
<EmptyState
  icon={Search}
  title="没有找到用户"
  description="请尝试其他搜索条件"
/>
```

### 4.6 ConfirmDialog

#### 用途

确认对话框，用于删除、提交等需要二次确认的场景。

#### Props

```ts
export interface ConfirmDialogProps {
  isOpen: boolean;
  onClose: () => void;
  onConfirm: () => void;
  title: string;
  description?: string;
  confirmText?: string;
  cancelText?: string;
  confirmVariant?: 'primary' | 'danger';
  isLoading?: boolean;
}
```

#### 结构

- 使用现有 `Modal` 组件。
- Footer 左侧 Cancel，右侧 Confirm。
- Confirm 按钮 variant 由 `confirmVariant` 控制。

#### 使用示例

```tsx
<ConfirmDialog
  isOpen={showDelete}
  onClose={() => setShowDelete(false)}
  onConfirm={handleDelete}
  title="确认删除"
  description="删除后无法恢复，是否继续？"
  confirmVariant="danger"
/>
```

### 4.7 Toast

#### 用途

全局通知，操作成功/失败后的反馈。

#### Props

```ts
export interface ToastProps {
  id: string;
  type: 'success' | 'error' | 'warning' | 'info';
  title: string;
  description?: string;
  duration?: number;
  onClose: (id: string) => void;
}
```

#### 样式

```tsx
'fixed right-4 top-4 z-toast flex w-80 items-start gap-3 rounded-lg border p-4 shadow-lg',
```

#### 类型颜色

| type | 边框 | 图标颜色 |
|---|---|---|
| success | `border-success/20` | `text-success` |
| error | `border-error/20` | `text-error` |
| warning | `border-warning/20` | `text-warning` |
| info | `border-info/20` | `text-info` |

#### 行为

- 默认 3 秒后自动消失。
- 提供关闭按钮。
- 多个 Toast 垂直堆叠，间距 8px。

#### 使用示例

```tsx
toast.success('保存成功');
toast.error('保存失败，请重试');
```

> Toast 需要配合全局 `ToastProvider` 使用。

### 4.8 Alert

#### 用途

页面内提示，常用于表单顶部、操作说明。

#### Props

```ts
export interface AlertProps extends React.HTMLAttributes<HTMLDivElement> {
  type: 'success' | 'error' | 'warning' | 'info';
  title?: string;
  description?: string;
  onClose?: () => void;
}
```

#### 样式

基于 Card，边框和图标颜色随 `type` 变化。

#### 使用示例

```tsx
<Alert
  type="warning"
  title="注意"
  description="当前操作不可逆，请谨慎处理。"
/>
```

## 5. 布局组件详细规范

### 5.1 AppShell

#### 用途

应用外壳，提供后台页面统一的侧边栏 + 顶部 Header + 内容区结构。

#### Props

```ts
export interface NavItem {
  href: string;
  icon: LucideIcon;
  label: string;
}

export interface AppShellProps {
  children: React.ReactNode;
  navItems: NavItem[];
  logo?: React.ReactNode;
  title?: string;
  userMenu?: React.ReactNode;
}
```

#### 结构

```tsx
<div className="min-h-screen bg-background">
  {/* Sidebar - 桌面端固定 */}
  <aside className="fixed left-0 top-0 z-sidebar hidden h-full w-64 border-r border-border-subtle bg-bg-secondary lg:block">
    <div className="flex h-16 items-center gap-3 border-b border-border-subtle px-6">
      {logo}
      <span className="text-lg font-bold">{title}</span>
    </div>
    <nav className="space-y-1 p-4">
      {navItems.map((item) => (
        <NavLink key={item.href} item={item} />
      ))}
    </nav>
  </aside>

  {/* Header */}
  <header className="fixed left-0 right-0 top-0 z-header flex h-16 items-center justify-between border-b border-border-subtle bg-bg-header/80 px-4 backdrop-blur lg:left-64 lg:px-8">
    <MobileMenu navItems={navItems} />
    <div className="flex items-center gap-4">
      {userMenu}
    </div>
  </header>

  {/* Main */}
  <main className="min-h-screen pt-16 lg:pl-64">
    <PageContainer>{children}</PageContainer>
  </main>
</div>
```

#### 移动端

- 桌面端：侧边栏固定显示。
- 移动端：侧边栏隐藏，Header 左侧显示汉堡菜单，点击后从左侧滑出 Drawer。

### 5.2 PageHeader

#### 用途

统一页面头部：标题、描述、面包屑、操作按钮。

#### Props

```ts
export interface BreadcrumbItem {
  label: string;
  href?: string;
}

export interface PageHeaderProps {
  title: string;
  description?: string;
  breadcrumbs?: BreadcrumbItem[];
  actions?: React.ReactNode;
  className?: string;
}
```

#### 结构

```tsx
<div className="mb-6">
  {breadcrumbs && <Breadcrumb items={breadcrumbs} />}
  <div className="flex flex-col gap-4 sm:flex-row sm:items-center sm:justify-between">
    <div>
      <h1 className="text-2xl font-bold text-text-primary">{title}</h1>
      {description && <p className="mt-1 text-text-tertiary">{description}</p>}
    </div>
    {actions && <div className="flex items-center gap-2">{actions}</div>}
  </div>
</div>
```

#### 使用示例

```tsx
<PageHeader
  title="用户管理"
  description="查看和管理平台注册用户"
  breadcrumbs={[{ label: '首页', href: '/admin' }, { label: '用户管理' }]}
  actions={<Button>新增用户</Button>}
/>
```

### 5.3 PageContainer

#### 用途

页面内容容器，控制最大宽度和内边距。

#### Props

```ts
export interface PageContainerProps {
  children: React.ReactNode;
  size?: 'sm' | 'md' | 'lg' | 'xl' | 'full';
  className?: string;
}
```

#### 尺寸

| size | max-width |
|---|---|
| sm | `max-w-3xl` |
| md | `max-w-4xl` |
| lg | `max-w-5xl` |
| xl | `max-w-7xl` |
| full | 无限制 |

#### 基础样式

```tsx
'mx-auto w-full p-6 lg:p-8',
```

### 5.4 ContentGrid

#### Props

```ts
export interface ContentGridProps {
  children: React.ReactNode;
```

```tsx

</ContentGrid>
```

### 5.5 Section

#### 用途

带标题的内容区块。

#### Props

```ts
export interface SectionProps {
  title?: string;
  description?: string;
  actions?: React.ReactNode;
  children: React.ReactNode;
  className?: string;
}
```

#### 结构

```tsx
<section className={cn('space-y-4', className)}>
  {(title || actions) && (
    <div className="flex flex-col gap-2 sm:flex-row sm:items-center sm:justify-between">
      <div>
        {title && <h2 className="text-lg font-semibold text-text-primary">{title}</h2>}
        {description && <p className="text-sm text-text-tertiary">{description}</p>}
      </div>
      {actions && <div className="flex items-center gap-2">{actions}</div>}
    </div>
  )}
  {children}
</section>
```
