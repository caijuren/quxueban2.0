# 趣学伴 Design System v2.8.1 — 核心页面视觉升级

> 版本：v2.8.1
> 目标：在 v2.8.0 Glass 能力基础上，将 Liquid Glass 设计语言落到用户价值最高的核心页面。

---

## 1. 背景

v2.8.0 已完成 Liquid Glass Foundation，提供了：

- Glass Token 与 CSS 工具类
- `GlassCard` 组件（支持 strength / hover / glow）
- 首页 IdentityCard 的 Demo 验证

v2.8.1 将进一步把 Glass 效果扩展到 4 个核心页面：

1. **首页 `/dashboard`**：顶部概览、快捷入口、数据卡片
2. **成长报告 `/dashboard/reports`**：报告头部、学科分析、周报导出
3. **AI 模块 `/dashboard/ai` 与 `/dashboard/ai-assistant`**：诊断卡片、对话气泡、输入区
4. **设置中心 `/dashboard/settings/*`**：设置头部、左侧导航、Section 卡片

---

## 2. 设计原则

1. **突出重点**：每个页面最多 1~2 个强 Glass 区域，其余使用标准卡片或实色。
2. **层次分明**：Glass 用于"浮在内容之上"或"需要强调"的元素，实色用于"承载内容"的容器。
3. **主题一致**：同一组件在深色/浅色下自动适配，不破坏可读性。
4. **渐进改造**：不一次性重写整个页面，只替换/增强关键卡片和容器。

---

## 3. 页面改造细则

### 3.1 首页 `/dashboard`

**改造范围**：顶部概览区、快捷操作卡、数据摘要卡

| 元素 | 改造方式 | Glass 强度 | Glow |
|---|---|---|---|
| 顶部 IdentityCard | 已改造为 `GlassCard strong + glow="primary"` | strong | primary |
| 快捷入口卡（今日任务/周计划/AI 助手） | 改为 `GlassCard default + hover` | default | none |
| 数据摘要卡（完成率/学习时长/连续打卡） | 改为 `GlassCard default + hover` | default | none |
| 风险提醒/待办卡 | 改为 `GlassCard subtle` | subtle | none |

**注意事项**：

- 快捷入口卡保持图标 + 标题 + 描述的简洁结构
- 悬停时统一使用 `glass-hover` 的抬升效果
- 数据卡中的大数字使用 `text-primary` 或品牌渐变

---

### 3.2 成长报告 `/dashboard/reports`

**改造范围**：报告头部 Hero 区、学科分析卡片、导出预览卡片

| 元素 | 改造方式 | Glass 强度 | Glow |
|---|---|---|---|
| 报告头部（标题 + 周选择器 + 孩子信息） | 改为 `GlassCard strong` 作为 Hero 背景 | strong | secondary |
| 学科分析卡片（语文/数学/英语） | 改为 `GlassCard default + hover` | default | none |
| 完成率概览卡片 | 改为 `GlassCard default` | default | none |
| 周报导出预览卡片 | 改为 `GlassCard strong` | strong | secondary |

**注意事项**：

- 报告头部使用 secondary glow，与"成长"主题呼应
- 学科卡片使用 subtle 顶部高光区分
- 周报导出卡片作为高价值操作，使用 strong + glow

---

### 3.3 AI 模块 `/dashboard/ai` 与 `/dashboard/ai-assistant`

**改造范围**：诊断卡片、对话气泡、输入框区域、推荐问题

| 元素 | 改造方式 | Glass 强度 | Glow |
|---|---|---|---|
| AI 诊断结果卡 | 改为 `GlassCard strong + glow="ai"` | strong | ai |
| 对话气泡（AI 回复） | 改为 `GlassCard subtle` | subtle | none |
| 对话输入框区域 | 改为 `GlassCard default` 浮动面板 | default | none |
| 推荐问题/快捷提示 | 改为 `GlassCard subtle + hover` | subtle | none |
| AI 能力入口卡 | 改为 `GlassCard default + hover` | default | ai |

**注意事项**：

- AI 模块统一使用紫色 secondary/ai glow
- 用户发送的消息保持实色背景（primary 或 secondary），与 AI 消息区分
- 输入框固定在底部时，使用 glass 浮动面板增强沉浸感

---

### 3.4 设置中心 `/dashboard/settings/*`

**改造范围**：设置头部、左侧导航、Section 卡片

| 元素 | 改造方式 | Glass 强度 | Glow |
|---|---|---|---|
| 设置页面头部（标题 + 用户摘要） | 改为 `GlassCard strong` | strong | primary |
| 左侧导航激活项 | 添加 glass 激活背景 + primary 光条 | subtle | none |
| Section 卡片 | 改为 `GlassCard default` | default | none |
| 重要设置项（AI 配置、账户安全） | 改为 `GlassCard default + hover` | default | none |
| 危险操作区（删除账户等） | 保持实色卡片，避免误操作 | solid | none |

**注意事项**：

- 设置页内容密集，Glass 强度以 default 为主
- 危险操作不玻璃化，保持视觉上的"稳重"和"警示"
- 左侧导航激活态增加左侧 3px primary 光条

## 4. 组件使用规范

### 4.1 默认组合

```tsx
// 高价值 Hero 区
<GlassCard strength="strong" glow="primary" className="p-6">
  <h2>标题</h2>
  <p>描述</p>
</GlassCard>

// 普通数据/操作卡
<GlassCard strength="default" hover className="p-5">
  <Icon />
  <h3>标题</h3>
</GlassCard>

// 浮动面板/提示
<GlassCard strength="subtle" className="p-4">
  提示内容
</GlassCard>
```

### 4.2 颜色与可读性

- Glass 卡片内部标题：使用 `text-primary`
- Glass 卡片内部描述：使用 `text-secondary`
- 需要强调的数值：使用 `text-primary` 或渐变文字
- 确保任意 Glass 上的文字对比度 ≥ 4.5:1

### 4.3 避免滥用

- 同一屏幕 Glass 卡片不超过 3 个 strong
- 内容密集的表格/列表不使用 Glass
- 表单输入区优先使用实色背景
