# 趣学伴 Design System v2.8.3 — 图标与字体升级

> 版本：v2.8.3
> 目标：建立统一、现代、有品牌感的图标与字体系统，强化"趣学伴"家庭教育品牌识别。

---

## 1. 背景

v2.8.2 已建立全局动效系统。当前图标与字体仍存在以下问题：

- 页面中直接 import Lucide 图标，尺寸/颜色/风格不统一
- 部分业务场景缺少专属图标（孩子、家庭、成长、AI 助手等）
- 中文标题在部分平台显示发虚，行高偏松散
- 关键数字在动画时宽度抖动
- 自定义 SVG 图标风格老旧，与整体设计不符

v2.8.3 将统一图标组件、优化字体栈、调整排版 Token。

---

## 2. 设计原则

1. **统一入口**：全站图标统一通过 `Icon` 组件使用，禁止业务页面直接 import Lucide。
2. **语义清晰**：图标尺寸/颜色/状态通过 props 控制，避免硬编码。
3. **品牌一致**：中文字体优先使用系统优质字体，数字使用稳定字体避免抖动。
4. **渐进替换**：优先替换 P0 页面图标，旧自定义 SVG 逐步清理。

---

## 3. 图标系统

### 3.1 `Icon` 组件

新增 `components/ui/icon.tsx`：

```tsx
<Icon name="Home" size="md" variant="default" className="text-primary" />
```

**Props：**

| Prop | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `name` | `LucideIconName` | 必填 | 图标名称，统一从 Lucide 映射 |
| `size` | `xs / sm / md / lg / xl` | `md` | 图标尺寸 |
| `variant` | `default / filled / gradient` | `default` | 图标变体 |
| `animate` | `spin / pulse / bounce` | - | 动画状态 |
| `className` | `string` | - | 扩展样式 |

### 3.2 尺寸规范

| Token | 像素 | 使用场景 |
|---|---|---|
| `xs` | 12px | 内联小标签、Badge 内 |
| `sm` | 16px | 按钮、表单提示 |
| `md` | 20px | 导航、列表项 |
| `lg` | 24px | 空状态、操作按钮 |
| `xl` | 32px | Hero 区域、功能入口 |

### 3.3 颜色规范

| 场景 | Token |
|---|---|
| 默认 | `text-secondary` |
| 激活/选中 | `text-primary` |
| 禁用 | `text-disabled` |
| 警告 | `text-warning` |
| 错误 | `text-error` |
| 成功 | `text-success` |

### 3.5 关键图标动画

- **AI 助手 Sparkles**：`animate-pulse` 微闪烁
- **加载中 Spinner**：`Loader2` + `animate-spin`
- **成功状态 Check**：`CheckCircle2` + 入场时 `ease-spring` 弹跳

### 3.6 清理旧图标

- 全局搜索 `lucide-react` 在页面/业务组件中的直接 import
- 替换为 `<Icon name="..." />`
- 删除 `public/icons/` 或 `components/icons/` 中风格不一致的自定义 SVG
- ESLint 规则后续扩展：禁止业务组件直接 import lucide 图标

## 4. 字体系统

### 4.1 中文字体栈

```css
--font-sans: "PingFang SC", "HarmonyOS Sans SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
--font-display: "PingFang SC", "HarmonyOS Sans SC", sans-serif;
```

- 标题使用 `PingFang SC` + 备选 `HarmonyOS Sans SC`
- 正文保持 `Manrope` + `PingFang SC`
- 保证 macOS / Windows / 移动端中文显示清晰

### 4.2 数字字体

```css
--font-mono: "SF Mono", "SFMono-Regular", "Menlo", "Monaco", "Consolas", monospace;
```

- 仪表盘、完成率等关键数字使用等宽或窄体
- 避免 CountUp 动画时数字宽度抖动

### 4.3 排版 Token 调整

| Token | 尺寸 | 字重 | 行高 | 使用场景 |
|---|---|---|---|---|
| `display` | 2.25rem (36px) | bold (700) | 1.2 | 首页大标题、报告总分 |
| `h1` | 1.875rem (30px) | semibold (600) | 1.25 | 页面标题 |
| `h2` | 1.5rem (24px) | semibold (600) | 1.3 | 区块标题 |
| `h3` | 1.25rem (20px) | medium (500) | 1.4 | 卡片标题 |
| `body` | 1rem (16px) | normal (400) | 1.6 | 正文 |
| `caption` | 0.875rem (14px) | normal (400) | 1.5 | 辅助说明 |
| `micro` | 0.75rem (12px) | medium (500) | 1.4 | 标签、时间 |

- 标题行高收紧（1.2 ~ 1.3）
- 正文行高保持 1.5 ~ 1.6

## 6. 技术实现要点

### 6.1 Icon 组件实现

```tsx
import { icons, type LucideIcon } from "lucide-react";
import { cn } from "@/lib/utils";

const sizeMap = { xs: 12, sm: 16, md: 20, lg: 24, xl: 32 };

interface IconProps {
  name: keyof typeof icons;
  size?: "xs" | "sm" | "md" | "lg" | "xl";
  variant?: "default" | "filled" | "gradient";
  animate?: "spin" | "pulse" | "bounce";
  className?: string;
}

export function Icon({ name, size = "md", animate, className }: IconProps) {
  const LucideIcon = icons[name] as LucideIcon;
  return (
    <LucideIcon
      size={sizeMap[size]}
      className={cn(
        "shrink-0",
        animate === "spin" && "animate-spin",
        animate === "pulse" && "animate-pulse",
        animate === "bounce" && "animate-bounce",
        className
      )}
    />
  );
}
```

### 6.2 字体加载

- 不引入外部中文字体文件（避免加载阻塞）
- 依赖系统字体栈，通过 Tailwind `font-sans` 配置生效

### 6.3 兼容性

- `lucide-react` 版本保持 `^0.408.0`，Icon 组件基于其图标映射
- 对不存在的图标名做 TypeScript 类型保护

## 8. 风险与应对

| 风险 | 影响 | 应对策略 |
|---|---|---|
| 图标全站替换工作量大 | 工期延长 | 优先 P0 页面，其他页面分阶段替换 |
| Lucide 某些业务图标缺失 | 语义不清 | 选择最接近的图标，必要时保留少量自定义 SVG |
| 字体栈在不同系统差异大 | 视觉不一致 | 增加充足备选字体，以系统字体为主 |
| 图标尺寸统一后布局错乱 | 回归问题 | 逐个页面检查，确保对齐和间距 |
